Aba 1 · Linguagens de programação: o que são e como funcionam

Sua missão é entender o que é uma linguagem de programação no back-end e saber por que existem tantas opções diferentes. Imagine que você precisa construir uma casa: você pode usar tijolos, madeira, aço ou concreto. Cada material tem suas vantagens. No back-end, a linguagem é o material com o qual você constrói o servidor, as regras do negócio e a conexão com o banco de dados.

📚 O que é uma linguagem de programação para back-end?

Uma linguagem de programação back-end é o conjunto de palavras e regras que usamos para escrever o código que roda no servidor — aquele motor escondido que faz o site funcionar. Quando você entra no site do iFood (aplicativo brasileiro de entrega de comida) e pede uma pizza, o que você vê na tela é o front-end, mas quem calcula o preço, consulta o estoque, grava o pedido e avisa o entregador é o back-end, escrito em uma linguagem específica.

Essa linguagem conversa com o sistema operacional (como Linux ou Windows Server), acessa bancos de dados (como MySQL ou PostgreSQL) e responde às requisições (pedidos) que chegam do navegador ou do aplicativo do celular.

🌎 Onde isso aparece no dia a dia?

  • Quando você paga uma conta no aplicativo do Nubank (banco digital brasileiro), o back-end em Java valida seu saldo, registra a transação e envia o comprovante.
  • Quando o Spotify (serviço de streaming de música) recomenda uma playlist para você, um back-end em Python processa milhões de dados sobre o que você costuma ouvir.
  • Quando o Mercado Livre (marketplace latino-americano) mostra os produtos em promoção, o back-end em Node.js (versão do JavaScript que roda no servidor) monta a página sob medida para você.

🛠️ As linguagens mais usadas no back-end

  • JavaScript (Node.js) — o mesmo JavaScript da web, agora rodando no servidor. Usado pelo Netflix (serviço de streaming) e pelo LinkedIn (rede profissional).
  • Python — linguagem simples e poderosa. Usada pelo Instagram (rede de fotos) e pelo Dropbox (serviço de arquivos na nuvem).
  • Java — linguagem robusta, muito usada em bancos e grandes empresas. Usada pelo Banco do Brasil e em sistemas do SUS (Sistema Único de Saúde).
  • PHP — linguagem antiga, mas ainda muito presente na web. Usada pelo WordPress (sistema que roda cerca de 40% dos sites do mundo).
  • C# (leia-se c-sharp) — da Microsoft, usada em sistemas corporativos que rodam na plataforma .NET (conjunto de ferramentas da Microsoft).
  • Go (ou Golang) — linguagem criada pelo Google, muito rápida. Usada pelo Uber (aplicativo de transporte) para lidar com milhões de pedidos simultâneos.
  • Ruby — linguagem elegante. Usada pelo GitHub (site onde programadores guardam código) nos primeiros anos.

Aba 2 · Escolhendo a linguagem certa para cada situação

Sua missão agora é aprender a escolher a linguagem certa. Não existe a melhor linguagem do mundo: existe a linguagem certa para cada cenário. É como escolher um veículo: para ir à padaria você usa bicicleta; para uma mudança, usa caminhão. No back-end, a escolha errada custa tempo, dinheiro e noites sem dormir.

📚 Critérios para escolher uma linguagem

Quando uma empresa vai iniciar um projeto back-end, ela avalia vários fatores. O primeiro é o tamanho do time: se a equipe é pequena e iniciante, Python ou Ruby são escolhas amigáveis; se é grande e experiente, Java ou Go dão mais controle. O segundo é a velocidade de entrega: startups (empresas novas de tecnologia) querem lançar rápido, e Node.js com JavaScript permite reutilizar código entre front-end e back-end. O terceiro é o desempenho: sistemas financeiros ou jogos com muitos jogadores precisam responder em milissegundos, e Go entrega isso.

🌎 Casos reais de escolha

  • Netflix (serviço de streaming de vídeo) começou em Java e migrou partes para Node.js para lidar com milhões de usuários simultâneos.
  • iFood (aplicativo brasileiro de entregas) usa Java no núcleo, por ser robusto, e Go nas partes menores e rápidas do sistema.
  • Nubank (banco digital brasileiro) escolheu Clojure (linguagem moderna que roda sobre a máquina virtual do Java) para ter segurança e muitas conexões ao mesmo tempo.
  • Instagram (rede social de fotos) usa Python com o framework Django (kit de ferramentas prontas) para entregar rápido.
  • Twitter (rede social de mensagens curtas) começou em Ruby e migrou para Java e Scala (linguagem que roda sobre Java) porque Ruby não aguentava o volume.

🛠️ Frameworks: os kits prontos das linguagens

Uma linguagem sozinha é como um jogo de ferramentas soltas. Um framework (do inglês, estrutura; em português, arcabouço) é um kit pronto que já vem com peças montadas. Por exemplo:

  • Python tem o Django (usado pelo Instagram) e o Flask (mais leve).
  • JavaScript (Node.js) tem o Express (minimalista) e o NestJS (robusto).
  • Java tem o Spring Boot (muito usado em bancos).
  • PHP tem o Laravel (moderno e produtivo).
  • Ruby tem o Ruby on Rails (famoso por ter criado o GitHub e o Airbnb).

Aba 3 · Sintaxe: a gramática das linguagens

Sua missão é entender que toda linguagem de programação tem uma gramática chamada sintaxe: o conjunto de regras que define como escrever para o computador entender. Assim como na língua portuguesa você precisa de sujeito, verbo e concordância, no código você precisa seguir a sintaxe da linguagem, senão o programa reclama com um erro de sintaxe e não roda.

📚 O que é sintaxe na programação?

Sintaxe é o conjunto de regras formais que define como os comandos devem ser escritos. Cada linguagem tem a sua, como cada idioma humano. Por exemplo, para mostrar algo na tela:

  • Em Python: print("Olá")
  • Em Java: System.out.println("Olá");
  • Em JavaScript: console.log("Olá");
  • Em PHP: echo "Olá";
  • Em Ruby: puts "Olá"

Todos fazem a mesma coisa — mostrar Olá — mas cada um escreve de um jeito. É como dizer boa tarde em português, buenas tardes em espanhol e good afternoon em inglês.

🌎 Quando a sintaxe quebra, o que acontece?

  • No GitHub (site onde programadores guardam código), quando você escreve código com sintaxe errada, o site marca o erro em vermelho e não salva até você corrigir.
  • No WhatsApp (aplicativo de mensagens), uma falha de código descoberta em 2019 permitia invadir o celular apenas com uma ligação perdida. A empresa corrigiu em poucos dias.
  • Na NASA (agência espacial dos Estados Unidos), em 1962, a sonda Mariner 1 foi perdida por causa de UM caractere faltando na sintaxe do código: um prejuízo de milhões de dólares da época.

🛠️ Elementos comuns da sintaxe

  • Variáveis: caixinhas que guardam informação. Em Python: nome = "Maria". Em Java: String nome = "Maria";.
  • Comentários: anotações para humanos, ignoradas pelo computador. Em Python usa-se # (cerquilha); em JavaScript, // (duas barras).
  • Ponto e vírgula (;): algumas linguagens (Java, PHP, C#) exigem no fim de cada comando. Outras (Python, Ruby) não.
  • Chaves {}: em Java, C#, JavaScript e PHP marcam blocos de código. Em Python, usa-se recuo (espaços no início da linha).

Aba 4 · Estruturas de decisão: if, else e switch

Sua missão é dominar as estruturas de decisão: os comandos que fazem o programa tomar decisões. Sem elas, o programa faria sempre a mesma coisa, como um robô sem cérebro. Com elas, o programa reage: se o usuário for maior de idade, deixa entrar; senão, bloqueia.

📚 O comando if (se... então)

O if é o comando mais fundamental da programação e significa se em inglês. Você escreve a condição entre parênteses e o bloco de ações entre chaves. Em português: SE a condição for verdadeira, faça o que está dentro das chaves.

Exemplo em JavaScript (Node.js):

if (idade >= 18) {
    console.log("Pode entrar na festa");
} else {
    console.log("Só com responsável");
}

O else significa senão: é o caminho alternativo. SE for maior de idade, entra; SENÃO, só com responsável.

🌎 Onde essas decisões aparecem?

  • No iFood: SE o endereço está dentro do raio de entrega, calcula a taxa; SENÃO, mostra não entregamos aqui.
  • No Nubank: SE a senha está correta, libera a conta; SENÃO, conta o erro e bloqueia após 3 tentativas.
  • Na Netflix: SE o usuário tem plano premium, libera 4 telas; SENÃO, libera só 1 tela.
  • No WhatsApp: SE o número está salvo nos contatos, mostra o nome; SENÃO, mostra só o número.

🛠️ Outros comandos de decisão

  • else if (senão se): para várias opções em sequência. Exemplo: se é A, faz X; senão se é B, faz Y; senão faz Z.
  • switch (do inglês, interruptor ou escolha): quando há muitas opções claras, como o status de um pedido (pendente, enviado, entregue, cancelado). Fica mais limpo que vários else if encadeados.
  • operador ternário: um if com else em uma linha só. Em JavaScript: idade >= 18 ? "entra" : "bloqueado".

Aba 5 · Estruturas de repetição: for, while e foreach

Sua missão é dominar as estruturas de repetição: os comandos que fazem o programa repetir ações. Sem elas, você teria que escrever a mesma linha mil vezes para processar mil produtos. Com elas, você diz uma vez repita isso N vezes e o computador faz o trabalho pesado.

📚 Por que repetimos coisas no código?

Programas reais lidam com volumes enormes de dados. O Mercado Livre processa milhões de produtos por dia. O Spotify cataloga bilhões de músicas. Seria impossível escrever um comando para cada item: daí entram os loops (laços de repetição).

Os três principais loops são:

  • for (para): quando você SABE quantas vezes vai repetir. Exemplo: repita 10 vezes, ou conte de 1 até 100.
  • while (enquanto): quando você NÃO sabe quantas vezes, mas tem uma condição. Exemplo: repita ENQUANTO houver produtos no estoque.
  • foreach (para cada): quando você quer percorrer uma lista de coisas. Exemplo: para cada cliente da lista, envie um e-mail.

🌎 Loops no seu dia a dia

  • No Spotify: um loop percorre todas as músicas que você ouviu para montar a playlist Descobertas da Semana.
  • No Google: um loop cataloga bilhões de páginas da web todos os dias para a busca funcionar.
  • No iFood: um loop calcula a rota do entregador passando por todos os pedidos do caminho.
  • No Banco do Brasil: um loop processa milhões de transações do dia e monta o seu extrato.
  • No WhatsApp: um loop entrega a sua mensagem para cada pessoa do grupo, uma por uma.

🛠️ Exemplos de sintaxe de loops

JavaScript:

// for clássico: de 1 a 5
for (let i = 1; i <= 5; i++) {
    console.log("Número " + i);
}

// foreach: para cada item da lista
const frutas = ["maçã", "banana", "laranja"];
for (const fruta of frutas) {
    console.log(fruta);
}

Python:

# for com intervalo
for i in range(1, 6):
    print("Número", i)

# foreach
frutas = ["maçã", "banana", "laranja"]
for fruta in frutas:
    print(fruta)

Regras de escrita da linguagem, como a gramática do português. Errou a sintaxe, o código não roda.
Variável
Caixinha com nome que guarda um valor: número, texto ou lista. Exemplo: idade = 25.
if e else
Comandos se e senão: fazem o programa escolher entre dois caminhos.
else if
Senão se: permite testar mais opções em sequência, entre o if e o else.
switch
Comando de escolha entre várias opções claras, como o status de um pedido. Mais limpo que muitos senão se.
for
Laço para quando você sabe quantas vezes repetir, como 10 vezes ou de 1 a 100.
while
Laço que repete enquanto uma condição for verdadeira, como enquanto houver estoque.
foreach
Laço que percorre cada item de uma lista, ideal para processar clientes, produtos ou mensagens.
i++
Incremento: soma 1 ao valor de i. Forma curta de i = i + 1.
Iteração
Uma volta completa do laço. Um laço com 10 iterações roda 10 vezes.
Concorrência
Capacidade de atender muitos pedidos ao mesmo tempo, crítica para aplicativos como Uber e WhatsApp.

👑 CHEFÃO — Desafio final

Enunciado: Você foi contratado pela LogiBR (empresa fictícia de entregas, inspirada no modelo da Loggi, startup brasileira de entregas rápidas) para criar o sistema de cálculo de frete. O sistema precisa:

  1. Receber o peso do pacote (em quilos) e a distância (em quilômetros).
  2. Aplicar regras: se o peso passar de 30 quilos, cobrar taxa extra de 20 reais; se a distância passar de 100 quilômetros, cobrar 1 real por quilômetro excedente.
  3. Processar uma lista de 5 pedidos de uma só vez e somar o valor total.
  4. Escolher a linguagem adequada e justificar com um exemplo real (iFood, Loggi ou Uber).

Pedidos da lista:

  • Pedido 1: 2 quilos, 50 quilômetros
  • Pedido 2: 35 quilos, 80 quilômetros (tem taxa extra de peso)
  • Pedido 3: 5 quilos, 150 quilômetros (tem taxa extra de distância)
  • Pedido 4: 10 quilos, 30 quilômetros
  • Pedido 5: 25 quilos, 200 quilômetros (tem taxa extra de distância)

O que você precisa entregar (no caderno ou em papel):

  1. Qual linguagem você escolheria (Python, Java, Node.js ou Go)? Justifique com 1 exemplo real de empresa que fez escolha parecida, usando os termos concorrência e framework (explicados na cola rápida).
  2. Escreva o código em pseudocódigo (português estruturado) usando um laço para cada item da lista (foreach) para percorrer os pedidos, um se (if) para as taxas extras e uma variável para acumular o total.
  3. Calcule manualmente o total dos 5 pedidos e compare com o resultado que o seu código produziria.
  4. Aponte UMA estrutura de decisão e UMA estrutura de repetição no seu código e explique, em linguagem simples, o que cada uma faz.
📚 Dica para o Chefão

Comece escolhendo a linguagem com a pergunta: vou precisar processar muitos pedidos ao mesmo tempo? Se sim, Go ou Node.js são boas escolhas. Se for um sistema interno pequeno, Python com Django é mais produtivo. No código, crie a variável total = 0 antes do laço e, dentro do laço, faça total = total + valor do pedido.
