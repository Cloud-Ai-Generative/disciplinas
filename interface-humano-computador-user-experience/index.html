📱 Bem-vindos às Aulas de Interface Humano-Computador e UX

Nesta disciplina, vamos explorar a fascinante relação entre as pessoas e as tecnologias digitais. O objetivo é entender como projetar sistemas, softwares e sites que sejam não apenas funcionais, mas principalmente intuitivos, acessíveis e agradáveis para quem os utiliza.

A Interface Humano-Computador (IHC) é a ciência que estuda a comunicação entre o usuário e o computador. Já o User Experience (UX) vai além: é a percepção geral que o usuário tem ao interagir com um produto, envolvendo emoções, valores e usabilidade.

Vamos aprender que um bom design não é apenas sobre "enfeitar" uma tela, mas sim sobre resolver problemas reais e guiar o usuário de forma natural até o seu objetivo.

"Design não é apenas como parece ou como se sente. Design é como funciona."
— Steve Jobs
