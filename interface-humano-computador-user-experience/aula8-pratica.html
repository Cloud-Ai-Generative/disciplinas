🧰 Glossário de ferramentas (leia uma vez!)
  • Avaliação de interfaces: processo de verificar se uma interface é usável, útil e agradável para o usuário.
  • Métodos de inspeção: especialistas analisam a interface sem envolver usuários reais (ex.: heurísticas de Nielsen).
  • Métodos empíricos: testes com usuários reais executando tarefas reais.
  • Card sorting (arranjo de cartões): técnica para descobrir como os usuários organizam mentalmente as informações.
  • Codescoberta: designer e usuário exploram a interface juntos, em voz alta.
  • Entrevista: conversa estruturada para entender necessidades, expectativas e dificuldades do usuário.

01 — Avaliação da interface

🌍 No mundo real
  • Test drive antes de comprar o carro: você não compra sem experimentar — avaliação de interface é o "test drive" do sistema.
  • Prova de sabor na cozinha: o chef prova o prato antes de servir — avaliação evita entregar produto ruim ao usuário.
🔤 Mini-dicionário
  • Avaliação da interface: processo sistemático de coletar dados sobre como os usuários interagem com o sistema.
  • Usabilidade: facilidade de uso (eficácia, eficiência, satisfação).
  • Experiência do usuário (UX): como o usuário se sente ao usar o sistema — vai além da usabilidade.

02 — Métodos para avaliação em interfaces

🌍 No mundo real
  • Inspeção = crítico de cinema: especialista analisa o filme sozinho, com base em conhecimento técnico.
  • Empírico = plateia no cinema: pessoas reais assistem e dizem o que acharam.
Mini-dicionário
  • Métodos de inspeção: especialistas analisam a interface (sem usuários). Ex.: heurísticas de Nielsen, walkthrough cognitivo.
  • Métodos empíricos: testes com usuários reais executando tarefas. Ex.: testes de usabilidade, observação, entrevistas.
  • Heurísticas: princípios gerais de usabilidade usados como "régua" para avaliar.

📋 INSTRUÇÕES PASSO A PASSO:
Passo 1: Abaixo aparece um método de avaliação.
Passo 2: Clique em Inspeção (especialista analisa sozinho) ou 👥 Empírico (com usuários reais).
Passo 3: Se acertar, avança. Se errar, tenta de novo.
Passo 4: São 6 métodos. Ao final, clique em "🔄 Jogar de novo".

Dica: inspeção = especialista sozinho; empírico = usuário real participando.

03 — Métodos empíricos

🌍 No mundo real
  • Test drive com cliente: você observa o cliente dirigindo e anota onde ele hesita, erra ou reclama.
  • Prova de prato com cliente: o cliente come e você anota: "fez cara boa? reclamou do sal?"
🔤 Mini-dicionário
  • Teste de usabilidade: usuário executa tarefas enquanto o avaliador observa e coleta dados.
  • Taxa de conclusão: porcentagem de tarefas que o usuário consegue terminar.
  • Tempo de tarefa: quanto tempo o usuário leva para concluir uma tarefa.
  • Erros: ações que desviam o usuário do caminho correto.
🎤 Plano de testes
  1. Passo 0 — entender a tela: simulador de teste de usabilidade com 5 usuários e 3 tarefas.
  2. Teste 1 — rodar o teste. Clicar: em "Simular teste" para ver os resultados. Vê: taxa de conclusão, tempo médio e erros. Significa: método empírico gera números concretos — não é opinião, é dado.
  3. Teste 2 — interpretar. Clicar: em "Interpretar resultados". Vê: análise do que os números significam. Significa: números altos de erro em uma tarefa indicam problema de design — é ali que devemos mexer.
📋 INSTRUÇÕES PASSO A PASSO:
Passo 1: Clique em "▶️ Simular teste" para rodar um mini teste de usabilidade.
Passo 2: Observe os resultados: taxa de conclusão, tempo médio e erros por tarefa.
Passo 3: Clique em " Interpretar resultados" para ver a análise.
Passo 4: Clique em "🔄 Novo teste" para simular com dados diferentes.

Dica: tarefa com muitos erros = problema de design; tarefa rápida e sem erros = design bom.
Clique em "Simular teste" para ver um mini teste de usabilidade em ação.

04 — Arranjo de cartões (Card Sorting)

No mundo real
  • Organizar a despensa: você pergunta à família: "onde cada um guardaria arroz, feijão, óleo?" — cada pessoa organiza de um jeito. Card sorting revela o "jeito mental" do usuário.
🔤 Mini-dicionário
  • Card sorting (arranjo de cartões): técnica em que o usuário agrupa itens (cartões) em categorias que fazem sentido para ele.
  • Aberto: o usuário cria as categorias com os nomes que quiser.
  • Fechado: o usuário distribui os itens em categorias já definidas pelo designer.
🎤 Plano de testes
  1. Passo 0 — entender a tela: 6 itens de um site de supermercado para organizar em 3 categorias.
  2. Teste 1 — agrupar. Clicar: em um item e depois na categoria desejada. Vê: o item vai para a categoria. Significa: card sorting revela como o usuário organiza mentalmente as informações — base para menus e navegação.
  3. Teste 2 — conferir. Clicar: em "Conferir agrupamento". Vê: quantos itens ficaram nas categorias "esperadas". Significa: quando muitos usuários agrupam igual, o designer tem certeza de como organizar o menu.
📋 INSTRUÇÕES PASSO A PASSO:
Passo 1: Abaixo aparecem 6 itens de um site de supermercado e 3 categorias.
Passo 2: Clique em um item (ele fica selecionado) e depois clique na categoria onde ele deve ficar.
Passo 3: Repita até todos os 6 itens estarem em alguma categoria.
Passo 4: Clique em "✅ Conferir agrupamento" para ver o resultado.
Passo 5: Clique em " Reiniciar" para refazer.

Dica: pense como um cliente de supermercado: onde você procuraria cada item?
Selecione um item e depois clique em uma categoria para agrupá-lo.

05 — Avaliação cooperativa

No mundo real
  • Cozinhar junto: chef e cliente cozinham juntos — o cliente fala o que está difícil, o chef ajusta na hora.
🔤 Mini-dicionário
  • Avaliação cooperativa: usuário e designer/avaliador trabalham juntos na interface — o usuário usa, o avaliador observa e faz perguntas no momento.
  • Diferença do teste comum: no teste tradicional o avaliador fica quieto; na cooperativa ele interage, pergunta "por que você fez isso?" na hora.
🎤 Plano de testes
  1. Passo 0 — entender a tela: jogo de classificar 6 situações como "Avaliação cooperativa" ou "Teste tradicional".
  2. Teste 1 — classificar. Clicar: no tipo correto para cada situação. Vê: acerto/erro com o porquê. Significa: avaliação cooperativa gera insights mais profundos, mas exige avaliador habilidoso para não influenciar o usuário.
INSTRUÇÕES PASSO A PASSO:
Passo 1: Abaixo aparece uma situação de avaliação.
Passo 2: Clique em 🤝 Cooperativa (avaliador interage) ou 🤐 Tradicional (avaliador só observa).
Passo 3: Se acertar, avança. Se errar, tenta de novo.
Passo 4: São 6 situações. Ao final, clique em " Jogar de novo".

Dica: cooperativa = avaliador pergunta e interage; tradicional = avaliador fica quieto observando.

06 — Codescoberta e entrevistas

🌍 No mundo real
  • Codescoberta: dois exploradores descobrindo uma cidade juntos — um mostra, o outro pergunta.
  • Entrevista: jornalista conversando com fonte para entender a história por trás dos fatos.
🔤 Mini-dicionário
  • Codescoberta: designer e usuário exploram a interface juntos, em voz alta — ambos aprendem.
  • Entrevista: conversa estruturada (com roteiro) para entender necessidades, expectativas e dificuldades do usuário.
  • Entrevista estruturada: perguntas fixas, na mesma ordem, para todos.
  • Entrevista semiestruturada: roteiro com perguntas-guia, mas liberdade para aprofundar.
🎤 Plano de testes
  1. Passo 0 — entender a tela: jogo de classificar 6 perguntas/situações como "Codescoberta" ou "Entrevista".
  2. Teste 1 — classificar. Clicar: no tipo correto para cada situação. Vê: acerto/erro com o porquê. Significa: codescoberta é sobre explorar junto (foco na interface); entrevista é sobre entender o usuário (foco na pessoa).
INSTRUÇÕES PASSO A PASSO:
Passo 1: Abaixo aparece uma pergunta ou situação.
Passo 2: Clique em 🔎 Codescoberta (explorar interface juntos) ou 🎤 Entrevista (conversa sobre necessidades).
Passo 3: Se acertar, avança. Se errar, tenta de novo.
Passo 4: São 6 situações. Ao final, clique em " Jogar de novo".

Dica: codescoberta = "vamos explorar esta tela juntos"; entrevista = "me conta sobre seu dia a dia".
🗺️ Mapa da aula (visão geral)

Avaliação (por que avaliar) → Métodos (inspeção × empírico) → Empíricos (teste de usabilidade com métricas) → Card sorting (organização mental) → Cooperativa (avaliador + usuário juntos) → Codescoberta e entrevistas (explorar e entender).

📝 Cola rápida (uma linha por termo)
  • Avaliação: descobrir problemas antes de lançar.
  • Inspeção: especialista analisa sozinho.
  • Empírico: usuário real executa tarefas.
  • Teste de usabilidade: taxa de conclusão, tempo, erros.
  • Card sorting: usuário agrupa itens — revela organização mental.
  • Cooperativa: avaliador interage durante o teste.
  • Codescoberta: designer e usuário exploram juntos.
  • Entrevista: conversa para entender necessidades.
