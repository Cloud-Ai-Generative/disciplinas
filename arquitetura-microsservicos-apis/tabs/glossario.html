📖 Glossário

Os termos de todas as sprints, em ordem alfabética. A cada sprint publicada, novos termos entram aqui.

TermoDefiniçãoSprint
AcoplamentoQuanto uma parte do sistema depende de detalhes de outra. Alto acoplamento espalha mudanças e falhas.0
ADRArchitecture Decision Record: registro de uma decisão de arquitetura com contexto, decisão, alternativas e consequências.0
C4Modelo de diagramas de arquitetura em quatro níveis: contexto, contêineres, componentes e código.0
ContêinerProcesso isolado que empacota uma aplicação com tudo de que ela precisa para rodar.0
DeployPublicação de uma nova versão do sistema em um ambiente.0
Docker ComposeFerramenta que sobe vários contêineres juntos a partir de um arquivo YAML.0
Falha em cascataQuando o problema de uma parte derruba outras partes que dependem dela.0
MigrationScript versionado que cria ou altera a estrutura do banco de dados.0
MonólitoSistema publicado como uma única unidade: um processo, um deploy e, em geral, um banco compartilhado.0
OpenAPIPadrão para descrever o contrato de uma API HTTP: rotas, parâmetros, respostas e erros.0
Problem DetailsFormato padronizado (RFC 9457) para respostas de erro em APIs HTTP.0
SMTPProtocolo de envio de e-mails. Na PagUai, o Mailpit recebe os e-mails para você visualizar.0
TransaçãoConjunto de operações no banco que acontece por inteiro (commit) ou é desfeito por inteiro (rollback).0
