🛠️ Problemas comuns

Todos os erros já encontrados nos laboratórios, organizados por tema. Cada sprint também tem o seu quadro "✋ Errou?". Antes de qualquer coisa, rode o diagnóstico rápido abaixo.

diagnóstico rápido, na pasta paguai
docker compose ps
docker compose logs api --tail 40
curl -i http://localhost:8080/health
🐳 Docker e Docker Compose
SintomaCausaSolução
Bind for 0.0.0.0:8080 failed: port is already allocatedOutro programa ou contêiner usa a porta (por exemplo, um Adminer em 8080)Descubra quem é: sudo ss -ltnp | grep :8080 (Linux), lsof -i :8080 (macOS), netstat -ano | findstr :8080 (Windows), docker ps. Pare o processo ou use outra porta: PAGUAI_API_PORT=8081 docker compose up -d
A API não acha o banco: Resource temporarily unavailable nos logsO contêiner da API ficou com a rede incompleta depois de uma falha anteriordocker compose down e depois docker compose up -d. Não basta religar o contêiner
Cannot connect to the Docker daemonDocker instalado, mas paradoAbra o Docker Desktop (Windows e macOS) ou sudo systemctl start docker (Linux)
WARN buildx Docker CLI plugin not foundDocker sem o plugin buildxSó um aviso. Para eliminá-lo no Linux: sudo apt install docker-buildx-plugin
Mudei o código, mas nada mudouA imagem não foi reconstruídadocker compose up -d --build
Quero o banco zerado, com os dados iniciaisO volume guarda os dados entre execuçõesdocker compose down -v e depois docker compose up -d

Portas configuráveis: PAGUAI_API_PORT (8080), PAGUAI_DB_PORT (5432), PAGUAI_MAIL_UI_PORT (8025) e PAGUAI_SMTP_PORT (1025).
