🐳 Docker e Docker Compose
SintomaCausaSolução
Bind for 0.0.0.0:8080 failed: port is already allocatedOutro programa ou contêiner usa a porta (por exemplo, um Adminer em 8080)Descubra quem é: sudo ss -ltnp | grep :8080 (Linux), lsof -i :8080 (macOS), netstat -ano | findstr :8080 (Windows), docker ps. Pare o processo ou use outra porta: PAGUAI_API_PORT=8081 docker compose up -d
A API não acha o banco: Resource temporarily unavailable nos logsO contêiner da API ficou com a rede incompleta depois de uma falha anteriordocker compose down e depois docker compose up -d. Não basta religar o contêiner
Cannot connect to the Docker daemonDocker instalado, mas paradoAbra o Docker Desktop (Windows e macOS) ou sudo systemctl start docker (Linux)
WARN buildx Docker CLI plugin not foundDocker sem o plugin buildxSó um aviso. Para eliminá-lo no Linux: sudo apt install docker-buildx-plugin
Mudei o código, mas nada mudouA imagem não foi reconstruídadocker compose up -d --build
Quero o banco zerado, com os dados iniciaisO volume guarda os dados entre execuçõesdocker compose down -v e depois docker compose up -d

Portas configuráveis: PAGUAI_API_PORT (8080), PAGUAI_DB_PORT (5432), PAGUAI_MAIL_UI_PORT (8025) e PAGUAI_SMTP_PORT (1025).

You are in 'detached HEAD' stateVocê abriu uma versão marcada por tag, não uma branchÉ normal para estudar. Para alterar o código a partir dela, crie uma branch: git switch -c meu-estudo-sprint-00
Your local changes ... would be overwritten by checkoutVocê mudou arquivos (por exemplo, o docker-compose.yml da fase 4) e tentou trocar de sprintGuarde as mudanças com git stash ou descarte com git restore . e repita o git checkout

Support for password authentication was removed ou Authentication failed no git pushO GitHub não aceita a senha da conta no terminalAutorize pelo VS Code (o primeiro git push abre o navegador) ou rode gh auth login. Veja a aba Ambiente, passo 7.3
Permission denied ou 403 no git pushO origin aponta para o repositório da disciplina, e não para o seu forkgit remote -v. Se aparecer Cloud-Ai-Generative/paguai, corrija: git remote set-url origin https://github.com/SEU-USUARIO/paguai.git
O GitHub pede a verificação em duas etapas e não deixa continuarO GitHub pode exigir a 2FA de contas que enviam códigoAtive em Settings → Password and authentication e guarde os códigos de recuperação
Não sei para onde o git push vai mandarO origin pode apontar para o seu fork ou para outro repositóriogit remote -v. O origin deve ser https://github.com/SEU-USUARIO/paguai.git. Veja o quadro "Fork, clone e origin" na aba Ambiente
Please tell me who you are no git commitO Git ainda não sabe o seu nome e o seu e-mailAba Ambiente, passo 3: git config --global user.name "Seu Nome" e git config --global user.email "seu-email" (o mesmo do GitHub)
code não é reconhecido como comando (ou command not found)O VS Code foi instalado sem o comando code no PATHWindows: reinstale deixando marcado Add to PATH. macOS: Command Palette → Shell Command: Install 'code' command in PATH. Depois, abra um terminal novo
git, docker ou dotnet não é reconhecido logo depois de instalarO terminal foi aberto antes da instalaçãoFeche o VS Code inteiro e abra de novo; se continuar, reinicie o computador
