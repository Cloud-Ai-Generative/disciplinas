🧰 Ambiente: prepare a sua máquina uma única vez

Faça esta aba antes da Sprint 0, Arquiteto(a). Escolha o seu sistema na barra acima das abas: os comandos mudam conforme a escolha. Marque cada passo quando terminar.

📈 Seu progresso0 de 0 passos

O progresso fica salvo só neste navegador. Recomeçar do zero

⏱️ Tempo total

De 45 a 70 minutos, quase todo de download e instalação.

💾 Máquina

8 GB de RAM ou mais e cerca de 10 GB livres em disco. Com menos, use o plano B (Codespaces), no fim desta aba.

🧭 O que você vai instalar

Git, Docker, VS Code e, se quiser, o .NET 10 SDK.

1 Git ⏱️ 5 min

O Git guarda o histórico do código. É com ele que você baixa a PagUai e troca de sprint pelas tags.

Windows · PowerShell
PowerShell
winget install --id Git.Git -e
🔍 Entenda o comando, parte por parte
wingeto instalador de programas do próprio Windows
installpede a instalação
--id Git.Gito identificador oficial do pacote do Git
-eexact: só aceita exatamente esse identificador
macOS · Terminal
Terminal
xcode-select --install

Instala as ferramentas de linha de comando da Apple, que incluem o Git. Se aparecer "already installed", o Git já está aí.

Linux · Ubuntu
terminal
sudo apt update && sudo apt install -y git
✅ Resultado esperado: abra um terminal novo e rode git --version. Aparece algo como git version 2.x.

2 Docker ⏱️ 15 a 25 min

O Docker roda a PagUai, o PostgreSQL e o Mailpit em contêineres, sem instalar nada disso na sua máquina.

Windows · PowerShell
PowerShell
winget install --id Docker.DockerDesktop -e

Depois, abra o Docker Desktop pelo menu Iniciar e aceite os termos. Se ele pedir o WSL 2, abra o PowerShell como administrador, rode o comando abaixo e reinicie o computador:

PowerShell (administrador)
wsl --install
macOS

Baixe o Docker Desktop na página oficial, escolhendo a versão do seu processador: Apple Silicon (M1 ou mais novo) ou Intel. Arraste para Aplicativos, abra e aceite os termos.

Linux · Ubuntu
terminal
curl -fsSL https://get.docker.com -o get-docker.sh
sudo sh get-docker.sh
sudo usermod -aG docker $USER
🔍 Entenda os comandos, parte por parte
curl -fsSL https://get.docker.com -o get-docker.shBaixa o script oficial de instalação do Docker.
curlprograma que acessa endereços da internet pelo terminal
-fsSLfalha se der erro, sem barra de progresso, mostrando os erros e seguindo redirecionamentos
-o get-docker.shsalva o conteúdo no arquivo get-docker.sh
sudo sh get-docker.shExecuta o script como administrador, instalando o Docker Engine e o Docker Compose.
sudo usermod -aG docker $USERColoca você no grupo docker, para usar o Docker sem sudo. Saia da sessão e entre de novo para valer.
✅ Resultado esperado: docker run --rm hello-world mostra a mensagem "Hello from Docker!".
⚠️ Armadilha: instalar não basta. O Docker precisa estar em execução (no Windows e no macOS, o Docker Desktop aberto). "Cannot connect to the Docker daemon" quase sempre é isso.

3 VS Code e extensões ⏱️ 10 min

PowerShell
winget install --id Microsoft.VisualStudioCode -e

Baixe em code.visualstudio.com e arraste para Aplicativos.

terminal
sudo snap install code --classic

Depois, instale as duas extensões que usamos:

terminal (qualquer sistema)
code --install-extension ms-dotnettools.csdevkit
code --install-extension humao.rest-client

C# Dev Kit: ler e navegar no código C#. REST Client: executar o arquivo requests/paguai.http.

4 .NET 10 SDK opcional ⏱️ 10 min

Só é necessário para rodar a API e os testes fora do Docker, no Aprofundamento. O laboratório Essencial funciona sem ele.

PowerShell
winget install --id Microsoft.DotNet.SDK.10 -e

Baixe o instalador do SDK na página oficial do .NET 10, na versão do seu processador.

terminal
curl -sSL https://dot.net/v1/dotnet-install.sh -o dotnet-install.sh
bash dotnet-install.sh --channel 10.0

O script instala em ~/.dotnet. Ele mostra, no fim, a linha para colocar essa pasta no PATH.

✅ Resultado esperado: dotnet --version mostra um número que começa com 10.

5 GitHub: fork e clone da PagUai ⏱️ 10 min

  1. Crie uma conta gratuita em github.com, se ainda não tiver.
  2. Abra Cloud-Ai-Generative/paguai e clique em Fork. Você ganha uma cópia sua do repositório.
  3. Clone o seu fork, trocando SEU-USUARIO pelo seu usuário do GitHub:
    terminal
    git clone https://github.com/SEU-USUARIO/paguai.git
cd paguai
git checkout sprint-00
    🔍 Entenda os comandos, parte por parte
    git clone https://github.com/SEU-USUARIO/paguai.gitBaixa o repositório inteiro, com todo o histórico e todas as tags.
    cd paguaiEntra na pasta criada pelo clone.
    git checkout sprint-00Coloca na sua pasta o código exatamente como ele estava no fim da Sprint 0. Cada sprint tem a sua tag.
✅ Resultado esperado: o Git avisa You are in 'detached HEAD' state. É normal: você está olhando uma versão marcada por tag, não uma branch. Veja "Git e tags" em Problemas comuns.
💼 O seu fork também é o seu portfólio. Você pode achar que o GitHub é só o lugar onde o código da disciplina fica guardado. Ele é também uma vitrine do seu trabalho. Ao longo das 14 sprints, o seu fork da PagUai vai reunir o que você construiu: um monólito que virou microsserviços, contratos de API, mensageria, contêineres, testes e os ADRs em que você justificou cada decisão. Empresas e recrutadores costumam olhar o perfil do GitHub para conhecer as tecnologias que a pessoa domina e como ela trabalha. Se você ainda não tem uma conta, crie uma; o plano gratuito atende toda a disciplina. Se já tem, este projeto entra ao lado dos que você já mostra.
  • Faça commits com mensagens claras, que contem o que você fez e por quê.
  • Escreva os seus ADRs. Eles mostram como você pensa, não só o código que você escreveu.
  • Fixe o repositório no seu perfil (botão "Customize your pins") e escreva no seu README pessoal o que você aprendeu.

A PagUai é uma empresa fictícia, e o código tem vulnerabilidades de propósito para as sprints de segurança. Diga isso a quem visitar o seu perfil: no README do seu fork ou na descrição do repositório.

6 Verificar o ambiente ⏱️ 2 min

Na pasta paguai, rode o script de verificação:

PowerShell, na pasta paguai
powershell -ExecutionPolicy Bypass -File .\scripts\check-env.ps1
🔍 Entenda o comando, parte por parte
powershellabre o PowerShell para rodar o script
-ExecutionPolicy Bypasslibera a execução só deste script, sem mudar a configuração do computador
-File .\scripts\check-env.ps1o script a executar
terminal, na pasta paguai
./scripts/check-env.sh
✅ Resultado esperado: todos os itens com [OK] e a mensagem Tudo pronto! Rode: docker compose up -d --build. Se você pulou o passo 4, o .NET aparece como [OPCIONAL] e não impede o "Tudo pronto!": ele só é necessário para rodar a API e os testes fora do Docker, no Aprofundamento.
☁️ Plano B: GitHub Codespaces

Pouca memória, computador da empresa sem permissão de instalar ou instalação travada? Use o Codespaces: um ambiente completo no navegador, já com Docker e .NET 10.

  1. No seu fork, clique em Code, aba Codespaces, e em Create codespace on main.
  2. Espere o ambiente abrir (alguns minutos na primeira vez) e siga os laboratórios no terminal dele.
🏢 Na empresaAmbientes de desenvolvimento na nuvem, como o Codespaces, são comuns em empresas grandes: todo o time começa com a mesma configuração. O plano gratuito do GitHub tem um limite mensal de horas; desligue o codespace quando não estiver usando.
