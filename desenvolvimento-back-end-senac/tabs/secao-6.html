📐 Consultar: encontrado ou não

📐 D-09 UML · Sequência GET /doacoes/{id}❓ o que é?

👀 Como ler: get_or_404 busca pela chave primária; se não acha, interrompe a rota e o formato único de erro (ADR 0007) monta a resposta.

api/app/routes.py (trecho)
@bp.get("")
def listar():
    doacoes = db.session.scalars(db.select(Doacao).order_by(Doacao.id)).all()
    return jsonify([d.to_dict() for d in doacoes])


@bp.get("/<int:doacao_id>")
def consultar(doacao_id):
    doacao = db.get_or_404(Doacao, doacao_id, description=NAO_ENCONTRADA)
    return jsonify(doacao.to_dict())
💡 Repare no <int:doacao_id>: o Flask só aceita números nessa posição. GET /doacoes/abc nem chega à função: responde 404 direto.

🔬 Aprofundamento opcional
1. Filtrar por tipo: GET /doacoes?tipo=alimento

A Dona Cida quer ver só os alimentos. Na função listar(), leia request.args.get("tipo") e, se vier, acrescente .where(Doacao.tipo == tipo) à consulta. Parâmetros de consulta (?tipo=) filtram uma coleção sem criar uma rota nova.

2. Quanto há em estoque de cada tipo?

Some as quantidades por tipo com db.select(Doacao.tipo, db.func.sum(Doacao.quantidade)).group_by(Doacao.tipo). Que rota REST você daria a esse resumo? Uma sugestão: GET /doacoes/resumo. Discuta com a turma os prós e contras.
