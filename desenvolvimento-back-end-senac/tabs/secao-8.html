🧠 Pergunta de verificação
1. Qual status a API deve devolver para uma doação com quantidade zero, e por quê?
2. A turma quer trocar o PostgreSQL por outro banco no servidor da associação. O que precisa mudar no código?
3. Onde deve ficar a regra "tipo deve ser alimento, roupa ou higiene"?
🔁 Recapitulando
  • Uma API REST organiza tudo em torno de um recurso (/doacoes), com verbos HTTP para as ações e códigos de status para o resultado.
  • O Docker Compose sobe API e banco iguais em qualquer máquina, com a configuração vinda do .env.
  • O projeto Flask está em camadas: rotas, validação, modelo, erros. Cada arquivo tem um motivo para mudar.
  • Nunca confie no cliente: a validação na API protege os dados e responde 400 com todas as mensagens de uma vez.
  • Cada escolha técnica tem um ADR com contexto, alternativas e consequências.
