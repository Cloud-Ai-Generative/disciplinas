📖 Glossário

Os termos da aula, em ordem alfabética. A coluna "Etapa" indica onde o termo aparece; "Time" é a aba 👥 O time e "Antes" é a trilha 🧰 Antes da aula.

TermoDefiniçãoEtapa
ADRArchitecture Decision Record: registro de uma decisão de arquitetura, com contexto, decisão, alternativas e consequências. Depois de aceito, vale para todo o time; para mudar, cria-se um novo ADR que substitui o anterior.2
APIConjunto de regras para que um programa peça coisas a outro. Aqui, o aplicativo pede à API que guarde e devolva doações.1
API FirstAbordagem em que o contrato da API é desenhado e acordado antes do código, permitindo que front-end e back-end trabalhem em paralelo. Também chamada de design-first ou contract-first.2
App factoryFunção (create_app()) que monta e devolve a aplicação Flask, permitindo criar versões com configurações diferentes, como nos testes.3
Back-endParte do sistema que roda no servidor: regras, dados e integrações.1
BacklogLista priorizada de tudo o que o produto ainda precisa ter, mantida pelo Product Owner.Time
BlueprintConjunto de rotas do Flask agrupado num módulo; aqui, todas as rotas de /doacoes.4
BranchLinha de trabalho dentro de um repositório. A principal se chama main; você cria a sua para mexer sem atrapalhar ninguém.3
CheckoutComando do Git que muda o projeto para outro ponto da história: uma tag, um branch ou um commit.3
CloneCópia de um repositório do GitHub para a sua máquina, com todo o histórico.Antes
Código de statusNúmero da resposta HTTP que indica o resultado: 2xx sucesso, 4xx erro do cliente, 5xx erro do servidor.2
CommitFoto do projeto num momento, com uma mensagem dizendo o que mudou.3
ContêinerProcesso isolado que roda uma imagem, com tudo de que a aplicação precisa.3
CRUDCreate, Read, Update, Delete: as quatro operações básicas sobre dados.2
Detached HEADAviso do Git quando você abre uma tag ou um commit antigo, fora de um branch. É normal; para trabalhar em cima, crie um branch.3
Docker ComposeFerramenta que sobe vários contêineres juntos a partir de um arquivo YAML.3
EndpointCombinação de verbo e rota que a API atende, como POST /doacoes.2
.envArquivo com as variáveis de ambiente (senhas, portas) da sua máquina. Não vai para o Git.3
ForkCópia de um repositório de outra pessoa na sua conta do GitHub, onde você pode enviar as suas mudanças.7
GitFerramenta que registra o histórico de mudanças de um projeto, na sua máquina.Antes
GitHubSite que guarda repositórios Git na internet e permite compartilhá-los.Antes
HealthcheckTeste periódico que o Docker faz para saber se um contêiner está pronto.3
História de usuárioDescrição curta de uma necessidade, no formato "Como [quem], quero [o quê], para [por quê]". Tradução de user story.1
ImagemModelo congelado de um ambiente (sistema, linguagem, dependências), descrito no Dockerfile.3
JSONFormato de texto para representar dados, com pares de chave e valor. É como a doação viaja entre o aplicativo e a API.2
MigrationScript versionado que cria ou altera a estrutura do banco. Próximo passo do projeto (ADR 0008).4
MockAPI de mentira que já responde de acordo com o contrato, para o front-end trabalhar antes de a API real ficar pronta.2
ModeloClasse Python que representa uma tabela do banco; aqui, Doacao.4
OpenAPIPadrão de mercado para escrever o contrato de uma API REST em um arquivo (YAML ou JSON), a partir do qual se geram documentação, mocks e testes.2
ORMObject-Relational Mapping: traduz objetos do Python em linhas do banco e vice-versa. Usamos o SQLAlchemy.4
Product Owner (PO)Papel do Scrum responsável por maximizar o valor do produto: define o que fazer e em que ordem.Time
PushEnvio dos seus commits da sua máquina para o GitHub.7
QA (testador)Quality Assurance: quem procura defeitos antes do usuário, testando casos normais e absurdos.Time
RecursoA "coisa" que uma API REST gerencia, identificada por um endereço; aqui, /doacoes.2
RepositórioPasta de um projeto com todo o seu histórico de mudanças.3
RESTEstilo de arquitetura para APIs baseado em recursos, verbos HTTP, representações (JSON) e requisições sem estado.2
Revolução 4.0Quarta Revolução Industrial (ou Indústria 4.0): integração do mundo físico com o digital por sistemas conectados, com nuvem, dados, automação e APIs.8
SeedDados iniciais de exemplo cadastrados no banco (flask seed).4
Tag (Git)Nome fixo para um ponto da história do código, como backend-senac-etapa-5.3
Tech leadPessoa desenvolvedora experiente que conduz as decisões técnicas do time.Time
ValidaçãoConferência dos dados recebidos contra as regras antes de gravar. Na API, protege o banco de qualquer cliente.5
Verbo HTTPIndica a ação sobre o recurso: GET lê, POST cria, PUT substitui, DELETE remove.2
VolumeÁrea de armazenamento do Docker que guarda dados fora do contêiner; eles sobrevivem ao docker compose down.3
