🐳 Docker e Docker Compose
SintomaCausaSolução
Cannot connect to the Docker daemonDocker instalado, mas paradoAbra o Docker Desktop (Windows e macOS) ou sudo systemctl start docker (Linux)
Bind for 0.0.0.0:8000 failed: port is already allocated (ou 5432)Outro programa já usa a porta: um contêiner de outro projeto seu (por exemplo, outro PostgreSQL) ou um programa instalado no computador1. Rode docker ps. Se um contêiner de outro projeto estiver na porta (coluna PORTS), pare-o com docker stop NOME e rode docker compose up -d. 2. Se nenhum contêiner usar a porta, é um programa instalado no computador: no .env, troque DB_PORT=5433 (ou API_PORT=8001) e rode docker compose up -d. Atenção: trocar o DB_PORT não muda nada na API nem nos comandos psql, só o acesso ao banco de fora do Docker. Se trocar o API_PORT, troque também a linha @base no início do requests.http (por exemplo, http://localhost:8001). Para descobrir qual programa (fora do Docker) usa a porta: netstat -ano | findstr :8000 (Windows), lsof -i :8000 (macOS), sudo ss -ltnp | grep :8000 (Linux)
