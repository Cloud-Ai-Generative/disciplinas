🧰 Glossário de ferramentas (leia uma vez!)
  • Criptografia: transformar dados legíveis em ilegíveis para proteger — só quem tem a chave consegue ler de volta.
  • Hash: "impressão digital" de um arquivo — um código único que muda se o arquivo for alterado.
  • Firewall: "porteiro" que filtra o que entra e sai da rede.
  • Antimalware: programa que detecta e remove vírus, ransomware e outras ameaças.
  • Backup: cópia de segurança dos dados para recuperar em caso de perda.

01 — Ameaças on-line × off-line

🌍 No mundo real
  • On-line: hacker tentando invadir seu computador pela internet agora mesmo.
  • Off-line: alguém roubando seu HD do notebook enquanto você não está olhando.
🔤 Mini-dicionário
  • Ameaça on-line: ataque que acontece pela rede, em tempo real, enquanto o sistema está conectado.
  • Ameaça off-line: ataque que acontece quando o atacante tem acesso físico ao dispositivo ou aos dados armazenados.

Passo 2: Clique em 🌐 On-line (se acontece pela rede) ou 💾 Off-line (se envolve acesso físico/disco).

02 — Criptografia simétrica

🌍 No mundo real
  • Cadeado com uma chave: você e seu amigo têm a MESMA chave — um tranca, o outro destranca. Se alguém roubar a chave, lê tudo.
Mini-dicionário
  • Criptografia simétrica: usa a MESMA chave para criptografar e descriptografar. Rápida, mas exige que ambos tenham a chave em segredo.
  • Chave: sequência secreta que transforma o texto legível em ilegível e vice-versa.
🎤 Plano de testes
  1. Passo 0 — entender a tela: simulação de criptografia simétrica com uma chave única.
  2. Teste 1 — criptografar. Clicar: em "Criptografar" para ver o texto virar código. Vê: o texto legível vira caracteres estranhos. Significa: a chave única transforma o conteúdo — só quem tem a mesma chave consegue ler de volta.
  3. Teste 2 — descriptografar. Clicar: em "Descriptografar" para voltar ao original. Vê: o código vira texto legível de novo. Significa: a mesma chave que trancou, destranca — por isso é "simétrica" (igual dos dois lados).
📋 INSTRUÇÕES PASSO A PASSO:
Passo 1: Digite uma mensagem no campo de texto.
Passo 2: Clique em "🔒 Criptografar" para ver a mensagem virar código.
Passo 3: Clique em "🔓 Descriptografar" para voltar ao original.
Passo 4: Observe: a mesma "chave" faz os dois processos.

Dica: criptografia simétrica = uma chave única para trancar e destrancar.
Digite uma mensagem e clique em "Criptografar" para ver a criptografia simétrica em ação.

03 — Criptografia assimétrica

🌍 No mundo real
  • Caixa de correio: qualquer um pode depositar carta (chave pública), mas só você tem a chave para abrir e ler (chave privada).
🔤 Mini-dicionário
  • Criptografia assimétrica: usa DUAS chaves: uma pública (para criptografar) e uma privada (para descriptografar).
  • Chave pública: pode ser compartilhada com todos — usada para criptografar.
  • Chave privada: fica só com o dono — usada para descriptografar.
🎤 Plano de testes
  1. Passo 0 — entender a tela: simulação de criptografia assimétrica com par de chaves.
  2. Teste 1 — criptografar com chave pública. Clicar: em "Criptografar (chave pública)". Vê: o texto vira código. Significa: qualquer um pode criptografar usando a chave pública — como depositar carta na caixa de correio.
  3. Teste 2 — descriptografar com chave privada. Clicar: em "Descriptografar (chave privada)". Vê: o código volta ao texto original. Significa: só o dono da chave privada consegue ler — como só você abre sua caixa de correio.
INSTRUÇÕES PASSO A PASSO:
Passo 1: Digite uma mensagem no campo de texto.
Passo 2: Clique em "🔒 Criptografar (chave pública)" para ver a mensagem virar código.
Passo 3: Clique em "🔓 Descriptografar (chave privada)" para voltar ao original.
Passo 4: Observe: chaves diferentes para trancar e destrancar.

Dica: criptografia assimétrica = chave pública (trancar) + chave privada (destrancar).
Digite uma mensagem e clique em "Criptografar (chave pública)" para ver a criptografia assimétrica em ação.

04 — Funções Hash

🌍 No mundo real
  • Impressão digital: cada pessoa tem uma única — se mudar algo, muda a impressão. Hash é a "impressão digital" do arquivo.
  • Lacre de envelope: se o lacre está rompido, alguém mexeu no conteúdo.
🔤 Mini-dicionário
  • Função Hash: transforma qualquer arquivo em um código fixo (hash) — se o arquivo mudar, o hash muda completamente.
  • Integridade: garantia de que o arquivo não foi alterado — verificada comparando hashes.
🎤 Plano de testes
  1. Passo 0 — entender a tela: simulação de função hash com verificação de integridade.
  2. Teste 1 — gerar hash. Clicar: em "Gerar Hash" para ver o código único do texto. Vê: um código estranho aparece. Significa: esse código é único para este texto — como uma impressão digital.
  3. Teste 2 — alterar e verificar. Clicar: mude uma letra do texto e clique em "Gerar Hash" de novo. Vê: o hash mudou completamente. Significa: qualquer alteração, por menor que seja, muda o hash — por isso detectamos adulterações.
📋 INSTRUÇÕES PASSO A PASSO:
Passo 1: Digite uma mensagem no campo de texto.
Passo 2: Clique em "🔐 Gerar Hash" para ver o código único.
Passo 3: Anote o hash gerado.
Passo 4: Mude UMA letra da mensagem e clique em "🔐 Gerar Hash" de novo.
Passo 5: Compare: o hash mudou completamente!

Dica: hash = impressão digital do arquivo; qualquer alteração muda o hash.
Digite uma mensagem e clique em "Gerar Hash" para ver a função hash em ação.

05 — CIA + Não-repúdio + Autenticação

🌍 No mundo real
  • Confidencialidade: carta em envelope fechado — só o destinatário lê.
  • Integridade: lacre no envelope — se romperam, você sabe.
  • Disponibilidade: correio funcionando todo dia — você recebe cartas quando precisa.
🔤 Mini-dicionário
  • Confidencialidade: só pessoas autorizadas podem acessar os dados.
  • Integridade: os dados não foram alterados indevidamente.
  • Disponibilidade: os dados estão acessíveis quando necessários.
  • Não-repúdio: quem enviou não pode negar que enviou.
  • Autenticação: verificar a identidade de quem está acessando.
🎤 Plano de testes

Passo 1: Abaixo aparece uma situação de segurança.
Passo 2: Clique no princípio que está sendo protegido (Confidencialidade, Integridade, Disponibilidade, Não-repúdio ou Autenticação).

Dica: confidencialidade = segredo; integridade = não alterado; disponibilidade = acessível; não-repúdio = não pode negar; autenticação = verificar identidade.

06 — Firewall, Antimalware, Backups e Políticas de Segurança

🌍 No mundo real
  • Firewall: porteiro do prédio — decide quem entra e quem sai.
  • Antimalware: segurança que revista as pessoas procurando armas.
  • Backup: cópia das chaves do carro — se perder a original, tem reserva.
  • Políticas de segurança: regras do condomínio — o que pode e o que não pode.
🔤 Mini-dicionário
  • Firewall: sistema que filtra o tráfego de rede, bloqueando acessos não autorizados.
  • Antimalware: software que detecta, previne e remove malware (vírus, ransomware, spyware).
  • Backup: cópia de segurança dos dados para recuperação em caso de perda.
  • Políticas de segurança: conjunto de regras que definem como a segurança deve ser implementada e mantida.

Dica: firewall = filtra rede; antimalware = remove vírus; backup = cópia de segurança; políticas = regras.
