⭐ Épicos no GitLab — criar no GRUPO e vincular issues · o passo que faltava

      
Atenção ao nível: épicos NÃO ficam no projeto — eles vivem no grupo (grupo-1). Disponíveis no plano Ultimate; sem eles, use o Plano B abaixo.

      
    
        
  1. Abra o grupo: breadcrumb do topo → secao-b › grupo-1 (ou lupa → “grupo-1”).
    2. 
        
  2. No menu do grupo: Planejar (Plan) → Épicos (Epics). (clássica: Plan › Epics · lupa: “epics”)
    3. 
        
  3. Clique em New epic (Novo épico) → Title: EPIC-01 — Fundação Ágil no GitLab → cole a descrição (botões ⧉ abaixo) → Create epic (Criar épico). Repita para os 4 épicos.
    4. 
        
  4. Vincular cada história: abra a issue no projeto (ex.: US-005) → coluna direita → widget Epics → selecione EPIC-02 — Arquitetura → a issue entra na árvore do épico.
    5. 
        
  5. Conferir: no grupo → Épicos → abra EPIC-02 → aba Issues lista US-005…US-010; o progresso do épico soma os weights das filhas.
    6. 
        
  6. (Opcional, turma inteira) no grupo secao-b: New epic “Atividade #1 — Sprint 1” e vincule os 4 épicos do grupo-1 como child epics (botão Add child epic dentro do épico pai).
    7.

  • Mapeada a Épico e Feature
  • Como/Quero/Para
  • Aceite + weight
  • Marco + responsável + revisor
  • ~backlog · DoR individual na própria história

  • MR ≥1 Approve + CI verde
  • Card em ~pronto
  • Artefato na Wiki
  • Issue fechada (Closes #)

🔁 Ciclo de vida de uma issue — Backlog → Pronto (ex.: US-005 · C4)

      

        
0 Planning: issue nasce 📥 ~backlog

          
Planejar›Tarefas›New issue›colar Markdown da história (⧉)

          
Direita: Weight 3 · Milestone Sprint 1 · Assignee Carla · Reviewers Diego · Labels ~backlog · Epics → EPIC-02 → Create issue.

          
BRUNO: “#5 no backlog, no épico 02, peso 3, dona Carla, revisor Diego.”

        
1 Começar: → Fazendo 📥 → 

          
Planejar›Quadros›Sprint 1›arrastar p/ “fazendo”

          
A etiqueta troca sozinha. Sem quadro: issue → Labels → troque. Confirme Assignee.

        
2 Branch + commits 🚧

          
Código›Branches›New branch›feature/US-005-diagramas-c4

          
Mermaid em docs/, commits docs(US-005): …, push.

        
3 MR: → Revisão 🚧 → 

          
banner “Create merge request”›Closes #5›Create MR

          
Card p/ 👀; revisor Diego notificado.

        
4 Revisão 👀

          
MR›Changes›comentar›Approve

          
Mudança? Card volta p/ 🚧; novo commit atualiza o MR.

        
5 Merge → Pronto 👀 → ✅

          
pipeline ✓›Merge

          
Issue fecha (Closes #5); burn down desce; card p/ ✅.

        
6 Wiki = Done ✅

          
Wiki›Create page›diagramas-c4-*›linkar na Home

          
Sem página, o card volta p/ 👀. O épico EPIC-02 avança no grupo.

        
7 Impedimento ~impedimento

          
quadro›New issue›Assignee = SM

          
Resolve e fecha; não pesa no marco.

        
8 Melhorias ~melhoria

          
New issue›Milestone Sprint 2

          
Feedback de Review/Retro nunca entra no meio da sprint.
