Hierarquia + projeto em branco · US-001

Hierarquia base: Seção (turma) › Grupo (time) › Projeto → ex.: secao-b › grupo-1 › taskflow-api.

  1. Ícone + → New group (Novo grupo) → secao-b (turma; pode já existir).
  2. Dentro dela: New subgroup (Novo subgrupo) → grupo-1.

Quadro ÚNICO do time (4 colunas) — reutilizado em toda sprint · US-005

      
Sim, um quadro só basta! As colunas são ligadas às etiquetas (não à sprint). A cada sprint você só filtra por Marco para enxergar as issues dela.

      
    
        
  1. Planejar (Plan) → Issue boards (Quadros de tarefas) → Create board (Criar quadro) → nome Scrum do Grupo (único, para sempre).
    2. 
        
  2. + Add list (Adicionar lista) ×4 → backlog, fazendo, revisao, pronto. Arrastar o card troca a etiqueta sozinho.
    3. 
        
  3. A cada sprint: ícone de filtro (funil) no topo do quadro → Milestone (Marco) = Sprint N → o quadro mostra só o sprint atual. Sem filtro, você vê o fluxo do grupo inteiro.
    4. 
      

      
💡 O que muda a cada sprint são as issues novas no marco — o quadro e as colunas permanecem os mesmos.

Criar as 16 histórias — cada uma com seu DoR/DoD (SEM template) · US-001…US-016

      
Na Planning, crie cada história manualmente e cole a descrição pronta (botão “Copiar Markdown da Issue” no backlog abaixo — já inclui aceite, DoR individual e DoD individual).

      
    
        
  1. No projeto: Planejar (Plan) → Tarefas (Issues) → New issue (Nova tarefa) → título US-0XX … → cole a descrição da história correspondente.
    2. 
        
  2. Na lateral direita: Weight (peso) · Milestone = Sprint 1 · Assignee = dono · Reviewers = revisor · Labels = ~backlog.
    3. 
        
  3. Vincular ao épico — 3 formas (use a que existir na sua instância):
    
          ① na lateral da issue, campo Epic → selecione o épico;
    
          ② ou abra o épico no grupo → Child items / Add issue → adicione a issue;
    
          ③ ou deixe escrito na descrição “Épico: EPIC-0X” + link #número da issue no épico.
    4. 
        
  4. Create issue. O card aparece na coluna 📥 Backlog do quadro.
    5.

0 Planning: issue criada à mão, com DoR/DoD próprios 📥 ~backlog

          
Planejar›Tarefas›New issue›colar descrição + lateral (weight/marco/dono/revisor/~backlog) + Epic

          
BRUNO: “#6 (US-006) no backlog, peso 3, dona Carla, revisor Diego, épico EPIC-02.”

        
1 Começar: Backlog → Fazendo

          
Planejar›Quadros›Scrum do Grupo (filtro: Sprint 1)›arrastar p/ “fazendo”

          
A etiqueta troca sozinha (~backlog → ~fazendo). Confirme o Assignee.

          
CARLA: arrasta na Daily e comenta “/assign @carla — começo hoje”.

        
2 Produzir em branch 🚧

          
Código›Branches›New branch›feature/US-006-diagramas-c4

          
Suba os Mermaid em docs/ com commits docs(US-006): … + push.

        
3 MR: Fazendo → Revisão

          
banner “Create merge request”›Compare & continue›Closes #6›Create MR

          
Arraste o card p/ 👀. Revisor = Diego.

        
4 Revisão 👀

          
MR›Changes›comentar›Approve

          
Pediu mudança? Card volta p/ 🚧; novo commit atualiza o MR sozinho.

        
5 Merge: Revisão → Pronto ✅

          
MR›Merge

          
Issue fecha sozinha; weight sai do “restante” → burn down desce.

        
6 Wiki = DoD de verdade

          
Wiki›Create page›diagramas-c4-*›Save + linkar na Home

          
Sem página na Wiki, o card volta p/ 👀.

        
7 Impedimento ~impedimento

          
quadro›New issue›~impedimento›Assignee = SM

          
SM resolve e fecha; não pesa no burn down.

        
8 Melhorias ~melhoria

          
New issue›~melhoria›Milestone = Sprint 2

          
Feedback da Review/Retro nunca entra no meio da sprint.
