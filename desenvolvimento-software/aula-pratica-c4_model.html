💡 Conceito em 60 Segundos: O Google Maps da Arquitetura

Criado por Simon Brown, o Modelo C4 resolve o caos dos diagramas de caixas e setas sem padrão (onde ninguém sabe o que uma linha pontilhada significa).

Ele organiza a arquitetura em 4 níveis hierárquicos de zoom: 1. Contexto (Context) → 2. Contêineres (Containers) → 3. Componentes (Components) → 4. Código (Code).

🗺️
Analogia do Google Maps: No nível 1 você vê o continente ou país (Contexto). Ao dar zoom, você vê a cidade e as rodovias principais (Contêineres). Mais zoom revela as ruas e quarteirões (Componentes). No zoom máximo, você vê a planta do imóvel (Código). Cada audiência olha o mapa no zoom apropriado!

💡 Conceito em 60 Segundos: Nível 1 - Diagrama de Contexto

O Diagrama de Contexto desenha a fronteira máxima entre o seu sistema e o mundo externo. Ele responde a 3 perguntas essenciais:

  • Quem são os atores/usuários? (Representados pelo elemento Person, em azul escuro).
  • Qual é o sistema em foco? (O bloco central que sua equipe constrói, em azul marinho).
  • Quais sistemas externos conversam com ele? (Gateway de pagamento, SEFAZ, Sistema Legado, serviços de e-mail - em cinza).

💡 Conceito em 60 Segundos: Nível 2 - Diagrama de Contêineres

Cuidado: No C4, um "Contêiner" NÃO significa Docker!

Para Simon Brown, um contêiner é qualquer unidade implantável e executável que roda código ou armazena dados de forma independente.

Exemplos legítimos de contêineres: Uma Single-Page Application (React), um aplicativo móvel (Flutter/iOS), uma API Backend (Go / Node.js / Java Spring), um Banco de Dados Relacional (PostgreSQL) ou uma Fila de Mensagens (RabbitMQ).

💡 Conceito em 60 Segundos: Diagrams as Code (C4-DSL)

Desenhar diagramas em ferramentas de desenho livre (Visio, Miro, PowerPoint) gera diagramas mortos: eles ficam desatualizados na primeira semana e ninguém consegue versionar no Git.

A abordagem moderna recomendada por Simon Brown é Diagrams as Code através da C4-DSL (Structurizr) ou C4-PlantUML: você escreve o modelo em texto declarativo puro, versiona com seu código no Git e renderiza os gráficos automaticamente nas pipelines de CI/CD.

Detalhes do Nível

📋 Cola Rápida (C4 Model Cheat Sheet)

Elemento / Conceito Nível Finalidade Principal Exemplo Típico
Person Nível 1 • Contexto Usuário humano, cliente, administrador ou operador que interage com o sistema. Cliente do Banco, Médico, Motorista
Software System Nível 1 • Contexto O sistema de mais alto nível que entrega valor aos usuários. Sistema de E-commerce, Internet Banking
External System Nível 1 • Contexto Sistema fora do seu controle de desenvolvimento (terceiros / legados). Gateway Stripe, API do WhatsApp, SEFAZ
Container Nível 2 • Contêineres Unidade implantável independente (código ou armazenamento). Não é só Docker! Single-Page App, API Gateway, Worker Go
Database Container Nível 2 • Contêineres Armazenamento estruturado, relacional, documental ou em cache. PostgreSQL, MongoDB, Redis, S3 Bucket
Component Nível 3 • Componentes Agrupamento de classes e módulos que formam a lógica de um único contêiner. SecurityFilter, OrderController, EmailSender
Code Nível 4 • Código Detalhe de implementação de classes, interfaces e funções (geralmente dispensável). Diagrama de Classes UML, Diagrama ER
Relationship Todos os Níveis Seta rotulada explicitamente com intenção e tecnologia/protocolo de transporte. "Consulta saldo usando [HTTPS/REST]"
