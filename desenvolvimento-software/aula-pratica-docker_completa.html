💡 Conceito em 60 Segundos: VM vs Container

Uma Máquina Virtual (VM) emula um computador inteiro com kernel próprio, gastando gigabytes de RAM e minutos para carregar. Um Container Docker é um processo isolado compartilhando o mesmo Kernel do sistema hospedeiro, iniciando em milissegundos.

🏗️
Analogia do Prédio: A VM é uma casa inteira com gerador próprio para cada morador; o Container é um apartamento que compartilha a fundação e o encanamento central do prédio (Kernel).

🛠️ Guia de Instalação Interativo

Selecione seu Sistema Operacional:

Roteiro para Windows 10/11:

  1. Ative a Virtualização (VT-x / AMD-V) na BIOS da sua placa-mãe.
  2. Abra o PowerShell como Administrador e execute: wsl --install.
  3. Baixe o Docker Desktop e mantenha marcada a opção "Use WSL 2 engine".

Roteiro para Ubuntu / Debian:

  1. Instale via script oficial automatizado: curl -fsSL https://get.docker.com | sh
  2. Execute o Docker sem precisar de `sudo`: sudo usermod -aG docker $USER

💡 Conceito em 60 Segundos: Port Mapping & Persistência de Dados

O isolamento de rede exige mapeamento de portas: -p 8080:80 (Host:Container). Para não perder dados com a destruição do container, conectamos Volumes persistentes (-v volume:/caminho/no/container).

🧪 Laboratório: Construtor Visual de Portas e Volumes

docker run -d -p 8080:80 -v site_dados:/usr/share/nginx/html --name meu-site nginx

💡 Conceito em 60 Segundos: Subindo MySQL no Docker

O MySQL exige a variável de ambiente -e MYSQL_ROOT_PASSWORD=... para ser inicializado com segurança. Sua porta padrão é 3306 e seus dados persistem no caminho /var/lib/mysql.

🐬 Laboratório: Provisionador e Inspetor de MySQL

docker run -d --name banco-producao -p 3306:3306 -e MYSQL_ROOT_PASSWORD=root123 -v mysql_dados:/var/lib/mysql mysql:8.0

💡 Conceito em 60 Segundos: Orquestração com docker-compose.yml

O Docker Compose permite gerenciar stacks multi-serviços (Frontend + MySQL + Redis) em um único arquivo YAML. Com docker compose up -d, toda a arquitetura sobe conectada em rede privada isolada.
