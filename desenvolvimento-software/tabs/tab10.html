🔤 Glossário A–Z (filtrável)

TermoDefinição curta
ADRArchitecture Decision Record: documento de uma decisão arquitetural (Contexto·Decisão·Alternativas·Consequências·Status).
Aggregate RootRaiz do agregado (DDD) que garante as invariantes do conjunto.
AdapterConcretiza uma porta p/ uma tecnologia (ex.: JPA/Mongo), isolando o domínio.
API-FirstDesenhar o contrato (OpenAPI) antes de implementar; mock via Prism.
BackfillCopia dados históricos p/ o novo banco (idempotente, upsert).
BearerEsquema de envio de token: Authorization: Bearer <token>.
Bounded ContextFronteira onde um modelo de domínio vale (DDD).
CI / CDIntegração Contínua (compila+testa a cada push) / Entrega ou Deploy Contínuo.
ContainerInstância em execução de uma imagem (processo isolado).
curlCliente HTTP de linha de comando p/ testar APIs.
DDDDomain-Driven Design: modelar pelo domínio (Evans, 2003).
DIPDependency Inversion: depender de abstrações, não de concreções.
DTOObjeto p/ transporte de dados (não expõe a entidade).
Dual-writeFase de migração que escreve nos dois bancos simultaneamente.
EndpointCada URL+verbo HTTP de uma API.
EREntidade-Relacionamento: modelagem de dados (tabelas, PK/FK).
FrameworkBiblioteca que inverte o controle (Spring, ASP.NET Core).
HealthcheckTeste periódico que marca o container como healthy.
IDEAmbiente de desenvolvimento integrado (IntelliJ, VS Code).
Imagem"Molde" leitura-only de um container.
JWTJSON Web Token: token assinado (header.payload.signature).
MockServidor falso que responde conforme o contrato (Prism).
ORMMapeamento objeto-relacional (Hibernate/JPA, EF Core).
OpenAPIEspecificação de APIs REST (YAML/JSON).
POMArquivo de projeto/dependências do Maven.
Porta (Hexagonal)Interface que o domínio define p/ entrada/saída (ex.: ProdutoRepository).
PrismMock server da Stoplight que sobe a partir do OpenAPI.
RESTEstilo de API por recursos e verbos HTTP.
RFC 7807Problem Details: padrão de corpo de erro (type/title/status/detail).
SDKMANGerenciador de JDKs/SDKs por projeto (shell POSIX).
SOLID5 princípios de design orientado a objetos.
Strangler FigPadrão de migração gradual (dual→backfill→cut-over).
TDDTest-Driven Development: RED→GREEN→REFACTOR.
Value ObjectObjeto sem identidade, comparado por valor (DDD).
VolumeArmazenamento persistente gerenciado pelo Docker.
WSL2Windows Subsystem for Linux 2 (kernel Linux real no Windows).
YAML / JSONFormatos de configuração / troca de dados.

❓ FAQ

Por que Java e C# ficam em abas separadas?

Para não misturar duas linguagens no mesmo passo a passo. Cada trilha é completa sozinha: Java nas Tabs 2 → 6 → 6-B (IntelliJ) e C# nas Tabs 3 → 7 → 7-B → 9 → 9-B (VS Code). As abas de contrato e de bancos (4, 5 e 8) servem às duas. Veja o 🗺️ Mapa das 15 abas, acima.

Os diagramas têm nome? Onde vejo qual é qual?

Sim: todo diagrama tem cabeçalho 📐 D-XX · tipo — nome. A lista completa, com a aba de cada um, está em 📐 Todos os diagramas, acima.

Estamos usando SOLID? Onde?

Sim. Cada aba de stack tem a tabela SOLID aplicado mapeando cada princípio (S/O/L/I/D) ao arquivo/concretização no projeto, com links.

SDKMAN só funciona no Linux?

Não só Linux: roda em Linux, macOS e Windows via WSL/Cygwin/MSYS (shell POSIX). Em CMD/PowerShell nativo do Windows NÃO funciona; use WSL ou instale o JDK manualmente/winget.

O que significa cada tag do openapi.yaml?

Abra o quadro "🔎 o que significa CADA tag" na Tab 4: explica linha a linha.

Onde valido o contrato e onde leio a especificação?

Validar: editor.swagger.io. Especificação: spec.openapis.org/oas/v3.1.0. Ambos linkados na Tab 4.

Por que os rostos do elenco são diferentes?

Silhuetas distintas que não dependem de modificador: 👩🏻 Mariana, 🧔 Rafael, 🧕🏾 Juliana, 👨🏿 Diego.

O simulador do Initializr já vem guiado?

Sim: recomendações pré-marcadas com ✅ rec e botão ↺ Voltar ao recomendado.

A Tab 4 tem botão de download?

Sim: 📦 Baixar ZIP desta aba no lab "Contrato final", levando openapi.yaml, ata.md, docker-compose.prism.yml, testes-mock.http e a collection Postman.
