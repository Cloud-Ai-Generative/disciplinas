❓ Por que o 3.14 e não o 3.15, que é o mais novo? O Python lança uma versão por ano, sempre em outubro: o 3.15 saiu em 09/10/2026 e o 3.14 em out/2025. Nas primeiras semanas de uma versão nova, algumas bibliotecas (inclusive peças do FastAPI, do Lab 2) ainda não têm pacote pronto para ela, e a instalação pode falhar. O 3.14 é estável, tem tudo pronto e recebe correções até 2030. Quando quiser, trocar de versão é só instalar a nova.

1🖱️ Baixar e instalar o Python 3.14 (Windows)

  1. Entre em python.org/downloads/windows (abre numa aba nova).
  2. Na lista Stable Releases ("versões estáveis"), procure a primeira Python 3.14.x (o x é o número do patch, o maior que aparecer) e clique em Download Windows installer (64-bit). (Só escolha ARM64 se o notebook tiver processador Snapdragon.)
  3. Abra o arquivo baixado (python-3.14.x-amd64.exe).
  4. ⚠️ O passo mais importante da aba: na primeira tela, embaixo, marque ☑ Add python.exe to PATH ("adicionar ao PATH"). Sem isso, o Windows não acha o Python depois.
  5. Clique em Install Now ("instalar agora") → Sim na pergunta de permissão. Espere a barra (1 a 2 minutos).
  6. Tela Setup was successful: se aparecer Disable path length limit ("desativar o limite de tamanho de caminho"), clique nele — evita um erro chato com pastas de nome longo. Depois, Close.
💡 E o "Python install manager"? O python.org passou a oferecer também um gerenciador de instalações para Windows (o comando py install), que facilita ter várias versões. Para quem está começando, o instalador clássico acima é mais simples. Os dois funcionam com esta aba.

② 👋 Laboratório 1: seu primeiro programa em Python (Hello World)

Objetivo: criar, rodar e entender seu primeiro programa. Ele escreve uma mensagem, pergunta seu nome e responde. Tempo: ~25 minutos. Repare: em Python não existe "criar projeto" — um programa é um arquivo .py, e pronto.

1🖱️ Criar a pasta e o arquivo

  1. No Explorador de Arquivos, dentro de Documentos\Projetos (a pasta das Tabs 2 e 3), crie a pasta hello-python (botão direito → Novo → Pasta).
  2. No VS Code: File → Open Folder… ("abrir pasta") → escolha hello-python → Select Folder. Se perguntar "Do you trust the authors…?" → Yes, I trust the authors.
  3. Na barra lateral (Explorer), passe o mouse sobre o nome da pasta e clique no ícone de arquivo com + (New File). Digite hello.py → Enter. O .py é a extensão dos arquivos Python.

2🖱️ Escrever e rodar o Hello World

No arquivo hello.py, digite uma linha só:

hello-python/hello.py — o Hello World 
print("Hello World!")
  1. Salve: Ctrl+S.
  2. No canto superior direito do editor aparece um ▶ (Run Python File, "rodar arquivo Python"). Clique nele.
  3. O painel TERMINAL abre embaixo e mostra:
resultado no painel TERMINAL 
Hello World!
🎉 Parabéns: você rodou seu primeiro programa em Python! Compare: em Java (Tab 2) foram 5 linhas, com classe e main; em Python, uma. O print = "mostre na tela"; o texto vai entre aspas. E não tem ;: em Python, a quebra de linha já termina a instrução.
⚠️ Não apareceu o ▶? A extensão Python não está instalada (passo ①.2), ou o arquivo não termina em .py. Pediu para escolher um interpretador (Select Interpreter)? Escolha o Python 3.14 da lista.

3Fazer o programa conversar com você — em 4 etapas

A cada etapa você acrescenta poucas linhas, salva (Ctrl+S), roda (▶) e vê o que mudou. As linhas novas estão marcadas com # ← NOVO.

Etapa A — duas linhas

hello-python/hello.py — etapa A 
print("Hello World!")
print("Estou aprendendo Python.")   # ← NOVO

Aparecem duas linhas, na ordem: o programa roda de cima para baixo. O # começa um comentário: tudo o que vem depois dele, na mesma linha, o Python ignora.

Etapa B — perguntar o nome

hello-python/hello.py — etapa B 
print("Hello World!")
print("Estou aprendendo Python.")

nome = input("Qual é o seu nome? ")     # ← NOVO
print("Olá, " + nome + "!")             # ← NOVO
Pedaço novoO que significa
input("Qual é o seu nome? ")Mostra a pergunta e para, esperando você digitar e apertar Enter.
nome = ...Cria uma variável chamada nome e guarda nela o que você digitou. Variável é uma caixa com etiqueta. Repare: não precisa dizer o tipo (em Java era String nome) — o Python descobre sozinho.
"Olá, " + nome + "!"O + junta textos.
⌨️ Onde digitar o nome: clique dentro do painel TERMINAL, logo depois da pergunta, digite e aperte Enter. (Diferente do C#, aqui o ▶ já roda no terminal: dá para digitar sem ajuste nenhum.)

Etapa C — decidir com if (e o recuo)

Rode e, na pergunta, só aperte Enter: sai "Olá, !". Vamos ensinar o programa a decidir:

hello-python/hello.py — etapa C (só o meio muda) 
nome = input("Qual é o seu nome? ")

if nome.strip() == "":          # ← NOVO
    nome = "visitante"          # ← NOVO (repare nos 4 espaços no começo)

print("Olá, " + nome + "!")
Pedaço novoO que significa
if ...:"Se". Os dois pontos no fim abrem o bloco.
nome.strip() == ""A pergunta: "o nome, sem os espaços das pontas, está vazio?". == é "é igual?" (comparar); = sozinho é "guarde".
os 4 espaços antes de nome = "visitante"É isto que diz o que está dentro do if. Em Java e C# são as chaves { }; em Python é o recuo. Não é enfeite: é obrigatório.
⚠️ IndentationError ("erro de recuo") é o erro nº 1 de quem começa em Python: a linha de dentro do if ficou sem os 4 espaços, ou com espaços demais. O VS Code já recua sozinho quando você aperta Enter depois dos :.

Gabarito: o programa completo, comentado

hello-python/hello.py (gabarito comentado, com 3 desafios no fim) 
# ════════════════════════════════════════════════════════════════════════════
#  hello.py — seu primeiro programa em Python
#
#  Como ler: o programa roda de CIMA para BAIXO, uma linha de cada vez.
#  Tudo o que começa com # é COMENTÁRIO: o computador ignora, é só para você.
#
#  Repare no que o Python NÃO tem, comparado ao Java (Tab 2) e ao C# (Tab 3):
#   • não tem ; no fim das linhas  → a quebra de linha já encerra a instrução
#   • não tem { } para os blocos   → quem marca o bloco é o RECUO (4 espaços)
#   • não precisa dizer o tipo     → nome = "Ana" já cria uma variável de texto
# ════════════════════════════════════════════════════════════════════════════

# 'import' traz uma ferramenta pronta do Python para este arquivo.
# datetime sabe a data e a hora — vamos usar só o ano.
from datetime import datetime

# ── 1) ESCREVER NA TELA ─────────────────────────────────────────────────────
# print(...) = "mostre isto e pule para a próxima linha".
# O texto (uma "string") vai entre aspas — simples '...' ou duplas "...".
print("Hello World!")

# ── 2) PERGUNTAR E GUARDAR A RESPOSTA ──────────────────────────────────────
# input(...) mostra a pergunta e ESPERA você digitar e apertar Enter.
# O que você digitou vai para dentro de uma VARIÁVEL chamada 'nome'.
nome = input("Qual é o seu nome? ")

# ── 3) TOMAR UMA DECISÃO ───────────────────────────────────────────────────
# if = "se". .strip() tira os espaços das pontas; se não sobrar nada, a
# pessoa só apertou Enter — trocamos por "visitante".
# Os DOIS PONTOS (:) abrem o bloco, e o RECUO de 4 espaços diz o que está
# dentro dele. Errou o recuo? O Python avisa: IndentationError.
if nome.strip() == "":
    nome = "visitante"

# ── 4) USAR NÚMEROS ─────────────────────────────────────────────────────────
# datetime.now() é a data e hora do seu computador; .year pega só o ano.
ano = datetime.now().year

# ── 5) MONTAR UMA FRASE COM VARIÁVEIS ──────────────────────────────────────
# O f antes das aspas liga a "f-string": o que estiver entre { } é trocado
# pelo valor da variável. {nome} vira "Ana", {ano} vira 2026.
print(f"Olá, {nome}! Bem-vindo ao Python em {ano}.")

# len(...) = quantos caracteres o texto tem (espaços contam).
print(f"Seu nome tem {len(nome)} caracteres.")

# ════════════════════════════════════════════════════════════════════════════
#  DESAFIOS (tente sozinho e rode de novo com o ▶):
#   1. Pergunte também a cidade e mostre: "Ana, de Recife".
#   2. Pergunte o ano em que a pessoa nasceu e calcule a idade.
#      Dica: nascimento = int(input("Ano de nascimento: "))
#   3. Se o nome tiver mais de 10 letras, escreva "Que nome comprido!".
# ════════════════════════════════════════════════════════════════════════════
⚠️ Erros comuns (e o que fazer):
  • IndentationError → recuo errado (veja a etapa C).
  • NameError: name 'Nome' is not defined → nome escrito diferente: Python diferencia maiúsculas de minúsculas (nome ≠ Nome, print ≠ Print).
  • SyntaxError: unterminated string literal → abriu aspas e não fechou.
  • SyntaxError: expected ':' → faltaram os dois pontos no fim da linha do if.
  • "Rodei e não mudou nada" → o arquivo não foi salvo (bolinha ● na aba). Ctrl+S.

③ 🌐 Laboratório 2: o mesmo Hello World, agora como API (FastAPI)

O que muda: no Lab 1, o programa conversava com você. Agora ele responde a outros programas pela rede, quando alguém acessa um endereço como http://localhost:8000/hello — é uma API, como nas Tabs 2 e 3. Para isso, usamos o FastAPI, o framework web mais usado em Python hoje. Tempo: ~30 minutos.

Palavra novaO que é
PacoteCódigo pronto que outras pessoas escreveram (o FastAPI é um). Fica no PyPI, a "loja" de pacotes do Python.
pipO instalador de pacotes: pip install fastapi baixa do PyPI. É o "Maven" / "NuGet" do Python.
Ambiente virtual (venv)Uma pasta só deste projeto (.venv) onde os pacotes são instalados. Assim, cada projeto tem as suas versões e um não atrapalha o outro. Analogia: em vez de guardar todas as ferramentas numa caixa da casa inteira, cada obra tem a sua caixa.
requirements.txtA lista dos pacotes que o projeto precisa — quem baixar o projeto instala tudo de uma vez.

1🖱️ Criar a pasta e os arquivos

  1. Crie a pasta Documentos\Projetos\hello-api e abra no VS Code (File → Open Folder…).
  2. Crie o arquivo requirements.txt (ícone de arquivo com + na barra lateral) e cole o conteúdo abaixo. Salve.
hello-api/requirements.txt 
# requirements.txt — a lista de pacotes que o projeto precisa.
# É o "pom.xml" (Java) / ".csproj" (C#) do Python, em versão bem simples.
# Instale tudo de uma vez, com o ambiente virtual ativo:
#     pip install -r requirements.txt
#
# fastapi[standard] = o FastAPI + os extras recomendados: o servidor (uvicorn)
# e o comando 'fastapi dev', que liga a API e reinicia sozinho a cada mudança.
fastapi[standard]
  1. Crie o arquivo main.py, cole o código abaixo e salve. Leia os comentários: eles explicam cada linha.
hello-api/main.py 
# ════════════════════════════════════════════════════════════════════════════
#  main.py — o mesmo Hello World, agora como API (Python + FastAPI)
#
#  FastAPI é o "kit" (framework) que faz o trabalho pesado de uma API: liga o
#  servidor, entende os endereços e converte as respostas para JSON. É o
#  equivalente do Spring Boot (Tab 2) e do ASP.NET Core (Tab 3).
#
#  Leia de cima para baixo, em 3 passos:
#     1. app = FastAPI()      → cria a aplicação
#     2. @app.get("/...")     → liga cada ROTA a uma função
#     3. fastapi dev main.py  → (no terminal) liga o servidor na porta 8000
# ════════════════════════════════════════════════════════════════════════════

from datetime import datetime, timezone   # data e hora (usamos UTC)
import platform                           # informações do Python que está rodando

from fastapi import FastAPI, HTTPException

# ── 1) A APLICAÇÃO ──────────────────────────────────────────────────────────
# 'title' aparece na página de documentação automática: http://localhost:8000/docs
app = FastAPI(title="Hello Python API", version="1.0")


# ── 2) AS ROTAS ─────────────────────────────────────────────────────────────
# A linha com @ em cima da função é um DECORADOR: uma "etiqueta" que avisa
# o FastAPI "quando chegar um GET em '/', chame esta função".
# Quem chama a função é o FastAPI, não você.
@app.get("/")
def raiz():
    # Um dicionário Python { "chave": valor } vira JSON automaticamente.
    return {
        "status": "API Python no ar",
        "rotas": ["GET /hello", "GET /hello/{nome}", "GET /docs"],
    }


# GET /hello — o "smoke test": se isto responde, o ambiente está pronto.
@app.get("/hello")
def hello():
    return {
        "mensagem": "Hello World com Python + FastAPI!",
        "python": platform.python_version(),                   # ex.: 3.14.2
        "horarioUtc": datetime.now(timezone.utc).isoformat(),   # sempre UTC em API
    }


# {nome} é um PARÂMETRO DE ROTA: em GET /hello/Ana, o FastAPI entrega "Ana"
# no parâmetro 'nome' da função (o nome precisa ser igual nos dois lugares).
# O ': str' é uma DICA DE TIPO: diz que 'nome' é texto. O FastAPI usa essa
# dica para validar o pedido e para montar a documentação em /docs.
@app.get("/hello/{nome}")
def hello_nome(nome: str):
    # Igual ao Lab 1: uma decisão com if. Nome gigante é recusado com
    # 400 Bad Request ("pedido inválido"). 'raise' INTERROMPE a função e
    # o FastAPI transforma o HTTPException numa resposta de erro em JSON.
    if len(nome) > 30:
        raise HTTPException(status_code=400, detail="Nome deve ter no máximo 30 caracteres")

    return {"mensagem": f"Olá, {nome}! Sua API Python está funcionando."}
🔗 Repare na ligação com o Lab 1: a rota /hello/{nome} faz o mesmo que o seu "qual é o seu nome?", com o nome vindo no endereço. E aparecem as mesmas peças: if, len(), f-string. Compare também com o HelloController da Tab 2 e o Program.cs da Tab 3: a ideia é idêntica — "quando pedirem este endereço, responda isto".

⚠️ Erros comuns:
  • fastapi: command not found / "não é reconhecido" → o terminal não está no ambiente virtual (falta o (.venv) no começo da linha). Abra um terminal novo no VS Code — ele entra sozinho — ou ative pelo comando do bloco "⌨️" acima.
  • ModuleNotFoundError: No module named 'fastapi' → os pacotes não foram instalados neste ambiente: pip install -r requirements.txt, com o (.venv) ativo.
  • A instalação falhou com erro de "Rust", "compiler" ou "wheel" → você está num Python novo demais (ex.: 3.15 recém-lançado) e falta pacote pronto para ele. Instale o 3.14, apague a pasta .venv e crie o ambiente de novo.
  • address already in use → a API já está ligada em outro terminal. Desligue a outra (Ctrl+C).

# ─────────────────────────────────────────────────────────────

④ 🧱 O que você acabou de usar

Interpretado × compilado

No Java e no C#, existe um passo de compilar (traduzir o programa inteiro antes de rodar). O Python é interpretado: o interpretador lê e executa o arquivo direto. Resultado: começar é mais rápido e o código é mais curto; em troca, alguns erros só aparecem quando aquela linha roda — no Java e no C#, o compilador avisaria antes.

Tipos: o Python descobre, mas você pode dizer

Em Python, nome = "Ana" já basta (tipagem dinâmica). No Lab 2 você viu def hello_nome(nome: str): o : str é uma dica de tipo, opcional para o Python, mas que o FastAPI usa para validar o pedido e montar o /docs. Projetos grandes usam dicas em todo lugar.

⑤ 🔀 Guardar seu código no GitHub

É exatamente o mesmo passo da Tab 3, porque é o mesmo VS Code: Tab 3 → parte ⑤ (instalar o Git, criar a conta, Publish to GitHub, o dia a dia de commits). Só uma diferença:

⚠️ Nunca envie a pasta .venv para o GitHub. Ela tem centenas de MB de pacotes, e qualquer pessoa recria com pip install -r requirements.txt. Na lista de arquivos do Publish to GitHub, desmarque .venv e __pycache__ — ou, melhor, crie antes o .gitignore abaixo na pasta hello-api: com ele, o Git ignora essas pastas sozinho.
