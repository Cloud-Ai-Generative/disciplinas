🛡️ O 10º Fator do Twelve-Factor App: Dev/Prod Parity

O 10º fator estabelece que o ambiente de desenvolvimento deve ser o mais parecido possível com o de produção. Divergências sutis (versão do JDK, libc, kernel) causam bugs silenciosos que só aparecem em produção.

🎯 Os 3 Pilares da Paridade

  1. Gerenciadores Declarativos: winget (Windows), apt (Linux), brew (macOS) — scripts auditáveis commitados no Git.
  2. Isolamento com WSL2: contêineres Docker sobre kernel Linux real (não emulado), com I/O e syscalls idênticos à produção.
  3. Trava de Versão via Git: .sdkmanrc (Java) e global.json (.NET) forçam a mesma versão de compiladores para todo o time.
🍳
Analogia da Cozinha Industrial: se cada chef usar balanças descalibradas e fogões diferentes, o prato nunca sai igual. Toda a rede usa a mesma fita métrica, os mesmos termômetros e a mesma bancada padronizada!

🔀 O que é Git? E GitHub vs GitLab?

Git é um sistema de controle de versão distribuído: registra o histórico de mudanças do código, permite branches (linhas paralelas), merge (junção) e rollback (voltar). Cada dev tem o repositório completo localmente.

  • Repositório (repo): o projeto + histórico.
  • Commit: um "snapshot" comentado das mudanças.
  • Branch: linha paralela (ex.: feat/x); main é a principal.
  • Remote / origin: a cópia no servidor (GitHub/GitLab).
  • push / pull: enviar / trazer mudanças do remote.
  • PR/MR (Pull/Merge Request): pedido de revisão p/ juntar um branch ao main.

🔑 JWT a fundo: o que é, por que e como funciona

JWT (JSON Web Token, RFC 7519) é um token auto-contido e assinado: ele carrega as claims (quem é você) dentro dele mesmo. Por isso o servidor não guarda sessão — só verifica a assinatura. É isso que dá escala horizontal (stateless).

Anatomia: header.payload.signature

  • header: algoritmo (HS256) e tipo (JWT), em base64url.
  • payload: as claims — sub (usuário), role, exp (expiração), iat (emissão) — em base64url. Atenção: base64 ≠ criptografia: qualquer um consegue ler; por isso nunca coloque dado sensível no payload.
  • signature: HMAC-SHA256(header.payload, secret). Qualquer alteração de 1 caractere invalida o token.

Por que o login é público e o resto não?

O POST /api/auth/login é o único endpoint que não pode exigir token — é ele que o emite. Por isso o contrato traz security: [] nele. Todos os demais exigem Authorization: Bearer <token>.

Fluxo em 4 passos

  1. Cliente envia credenciais ao login.
  2. Servidor valida e emite o JWT assinado com o secret.
  3. Cliente guarda o token e o envia em cada request seguinte.
  4. Servidor verifica assinatura + expiração e autoriza (ou 401).

Aprofundar: RFC 7519 (JWT) · jwt.io (debugger interativo) · OWASP JWT Cheat Sheet.

⚠️ Erros comuns: token expirado (exp); secret errado/trocado; esquecer o prefixo Bearer ; achar que base64 criptografa (não criptografa!). Onde guardar o secret: variável de ambiente / secret manager — nunca commitado.

ADR-001 · Contrato OpenAPI como fonte únicaAceita


Contexto: frontend/mobile bloqueados aguardando backend.


Decisão: contrato OpenAPI 3.1 primeiro + mock Prism; negociado na Sala de Contrato.


Alternativas consideradas: code-first (rejeitada); GraphQL (fora de escopo).


Consequências: (+) desenvolvimento paralelo; (−) cerimônia inicial de desenho.


Status: Aceita · Stakeholders: Backend, Frontend, QA, Produto.


ADR-005 · JWT statelessAceita


Contexto: autenticação sem sessão em servidor.


Decisão: Bearer JWT HMAC-SHA256; erros em RFC 7807.


Alternativas consideradas: sessão em servidor/cookie (rejeitada); OAuth2 completo (adiado).


Consequências: (+) stateless, escala horizontal; (−) revogação exige blacklist/refresh.


Status: Aceita · Stakeholders: Backend, SRE, Segurança.


ADR-007 · Mock Prism em validação estrita (-m false)Aceita


Contexto: mock dinâmico mascarava erros de contrato.


Decisão: Prism com -m false valida o body contra o schema e retorna 400 quando não bate.


Alternativas consideradas: mock dinâmico default (rejeitada); mock manual (rejeitada).


Consequências: (+) QA pega erros de contrato cedo; (−) mock menos "mágico".


Status: Aceita · Stakeholders: QA, Backend, Frontend.


ADR-008 · Erros no padrão RFC 7807 (application/problem+json)Aceita


Contexto: erros ad-hoc dificultavam tratamento no cliente.


Decisão: todos os erros usam Problem Details (type/title/status/detail).


Alternativas consideradas: envelope custom {erro} (rejeitada); HTML error pages (rejeitada).


Consequências: (+) clientes parseiam erros de forma uniforme; (−) exige disciplina de emitir Problem Details.


Status: Aceita · Stakeholders: Backend, Frontend, QA.

🐳 Imagem vs Container vs Volume vs Porta


    

  • Imagem: o "molde" leitura-only (camadas de filesystem + metadados). Feita por docker build ou baixada de um registry.
    • 

  • Container: uma instância em execução da imagem (processo isolado). Pode haver vários containers da mesma imagem.
    • 

  • Volume: armazenamento persistente gerenciado pelo Docker (sobrevive ao remover o container). Usado p/ dados dos bancos.
    • 

  • Porta (ports:): mapeamento host:container (ex.: 3306:3306) que expõe o serviço ao host. Sem ports:, só outros containers na mesma rede acessam.
    • 



1. Rede Bridge


DNS interno pelo nome: mysql-db:3306, mongo-db:27017; só ports: expõe ao host.


2. Volumes vs Bind Mounts


    

  • Volumes: persistem (dados).
    • 

  • Bind Mounts: pasta do host mapeada (scripts/configs).
    • 



3. Healthcheck


Teste periódico (ex.: mysqladmin ping) marca o container como healthy.

/**

 * Registrado como bean via CoreBeansConfig (não tem @Service — é classe pura).
 */
public class ProdutoServiceImpl implements ProdutoService {

    private final ProdutoRepository repository;

    public ProdutoServiceImpl(ProdutoRepository repository) {
        this.repository = repository;
    }

    @Override
    public Produto criarProduto(Produto p) {
        if (p.getNome() == null || p.getNome().trim().isEmpty())
            throw new DomainException("O nome do produto é obrigatório");
        if (p.getNome().trim().length() < 2)
            throw new DomainException("O nome deve ter pelo menos 2 caracteres");
        if (p.getPreco() == null || p.getPreco().compareTo(BigDecimal.ZERO) <= 0)
            throw new DomainException("O preço deve ser maior que zero");
        if (p.getEstoque() == null || p.getEstoque() < 0)
            throw new DomainException("O estoque não pode ser negativo");
        return repository.salvar(p);
    }

    @Override
    public List<Produto> listarProdutos() {
        return repository.listarTodos();
    }

        var all = repository.listarTodos();
        int from = Math.min(page * size, todos.size());
        int to = Math.min(from + size, todos.size());
        return todos.subList(from, to);

package com.loja.infrastructure.persistence;

import com.loja.domain.Produto;
import com.loja.domain.ProdutoRepository;
import org.springframework.boot.autoconfigure.condition.ConditionalOnProperty;
import org.springframework.stereotype.Repository;
import java.util.List;
import java.util.Optional;

/** Adapter JPA — implementa a porta do domínio (Hexagonal). */
@Repository
@ConditionalOnProperty(name = "persistence.provider", havingValue = "relational", matchIfMissing = true)
public class ProdutoRepositoryAdapter implements ProdutoRepository {

    public ProdutoRepositoryAdapter(SpringDataProdutoRepository jpaRepo) {
        this.jpaRepo = jpaRepo;

    @Override public List<Produto> listarTodos() { return jpaRepo.findAll().stream().map(this::toDomain).toList(); }

    @Override public void deletarPorId(Long id) { jpaRepo.deleteById(id); }

        ProdutoJpaEntity e = new ProdutoJpaEntity();
        e.setId(d.getId()); e.setNome(d.getNome()); e.setPreco(d.getPreco()); e.setEstoque(d.getEstoque());

package com.loja.infrastructure.mongo;

import com.loja.domain.Produto;
import com.loja.domain.ProdutoRepository;
import org.springframework.boot.autoconfigure.condition.ConditionalOnProperty;
import org.springframework.data.mongodb.core.MongoTemplate;
import org.springframework.data.mongodb.core.query.Criteria;
import org.springframework.data.mongodb.core.query.Query;
import org.springframework.stereotype.Repository;
import java.util.List;
import java.util.Optional;

/** Adapter Mongo — mesma porta, tecnologia diferente (Liskov/Open-Closed). */
@Repository
@ConditionalOnProperty(name = "persistence.provider", havingValue = "nosql")
public class MongoProdutoRepository implements ProdutoRepository {

    private final MongoTemplate mongo;

    public MongoProdutoRepository(MongoTemplate mongo) { this.mongo = mongo; }

    @Override public Produto salvar(Produto p) {
        ProdutoMongoDocument doc = toDoc(p);
        doc = mongo.save(doc);
        return toDomain(doc);
    }
    @Override public Optional<Produto> buscarPorId(Long id) {
        Query q = new Query(Criteria.where("idLegado").is(id));
        return Optional.ofNullable(mongo.findOne(q, ProdutoMongoDocument.class)).map(this::toDomain);
    }
    @Override public List<Produto> listarTodos() {
        return mongo.findAll(ProdutoMongoDocument.class).stream().map(this::toDomain).toList();
    }
    @Override public boolean existePorId(Long id) { return buscarPorId(id).isPresent(); }
    @Override public void deletarPorId(Long id) {
        mongo.remove(new Query(Criteria.where("idLegado").is(id)), ProdutoMongoDocument.class);
    }

    private ProdutoMongoDocument toDoc(Produto d) {
        ProdutoMongoDocument doc = new ProdutoMongoDocument();
        doc.setIdLegado(d.getId()); doc.setNome(d.getNome());
        doc.setPreco(d.getPreco()); doc.setEstoque(d.getEstoque());
        return doc;
    }
    private Produto toDomain(ProdutoMongoDocument doc) {
        return new Produto(doc.getIdLegado(), doc.getNome(), doc.getPreco(), doc.getEstoque());
    }
}

@Repository

presentation/security/JwtService.java

package com.loja.presentation.security;

import io.jsonwebtoken.*;
import io.jsonwebtoken.security.Keys;
import org.springframework.beans.factory.annotation.Value;
import org.springframework.stereotype.Service;
import java.security.Key;
import java.util.Date;

/** Gera e valida JWT (HMAC-SHA256). */
@Service
public class JwtService {

    private final Key key;
    private final long expiration;

    public JwtService(@Value("${jwt.secret}") String secret,
                      @Value("${jwt.expiration}") long expiration) {
        this.key = Keys.hmacShaKeyFor(secret.getBytes());
        this.expiration = expiration;
    }

    public String gerarToken(String username, String role) {
        return Jwts.builder()
                .setSubject(username)
                .claim("role", role)
                .setIssuedAt(new Date())
                .setExpiration(new Date(System.currentTimeMillis() + expiration))
                .signWith(key, SignatureAlgorithm.HS256)
                .compact();
    }

    public Claims extrairClaims(String token) {
        return Jwts.parserBuilder().setSigningKey(key).build().parseClaimsJws(token).getBody();
    }

    public boolean isTokenValido(String token) {
        try { extrairClaims(token); return true; }
        catch (JwtException e) { return false; }
    }
}

package com.loja.presentation.security;

import io.jsonwebtoken.Claims;
import jakarta.servlet.FilterChain;
import jakarta.servlet.ServletException;
import jakarta.servlet.http.HttpServletRequest;
import jakarta.servlet.http.HttpServletResponse;
import org.springframework.security.authentication.UsernamePasswordAuthenticationToken;
import org.springframework.security.core.authority.SimpleGrantedAuthority;
import org.springframework.security.core.context.SecurityContextHolder;
import org.springframework.stereotype.Component;
import org.springframework.web.filter.OncePerRequestFilter;
import java.io.IOException;
import java.util.List;

/** Filtra requisições, valida "Bearer ...", popula SecurityContext. */
@Component
public class JwtTokenFilter extends OncePerRequestFilter {

    private final JwtService jwtService;

    public JwtTokenFilter(JwtService jwtService) { this.jwtService = jwtService; }

    @Override
    protected void doFilterInternal(HttpServletRequest req, HttpServletResponse res, FilterChain chain)
            throws ServletException, IOException {
        String header = req.getHeader("Authorization");
        if (header != null && header.startsWith("Bearer ")) {
            String token = header.substring(7);
            if (jwtService.isTokenValido(token)) {
                Claims claims = jwtService.extrairClaims(token);
                var auth = new UsernamePasswordAuthenticationToken(
                    claims.getSubject(), null,
                    List.of(new SimpleGrantedAuthority("ROLE_" + claims.get("role", String.class))));
                SecurityContextHolder.getContext().setAuthentication(auth);
            }
        }
        chain.doFilter(req, res);
    }
}

    @ExceptionHandler(DomainException.class)
    public ResponseEntity<ProblemDetail> handleDomain(DomainException ex) {
        ProblemDetail pd = ProblemDetail.forStatusAndDetail(HttpStatus.BAD_REQUEST, ex.getMessage());
        pd.setType(URI.create("https://example.com/erros/dominio"));
        pd.setTitle("Regra de negócio violada");
        return ResponseEntity.status(HttpStatus.BAD_REQUEST)
                .contentType(MediaType.APPLICATION_PROBLEM_JSON).body(pd);
    }

    @ExceptionHandler(MethodArgumentNotValidException.class)
    public ResponseEntity<ProblemDetail> handleValidation(MethodArgumentNotValidException ex) {
        String detail = ex.getBindingResult().getFieldErrors().stream()
                .map(fe -> fe.getField() + ": " + fe.getDefaultMessage())
                .collect(Collectors.joining("; "));
        ProblemDetail pd = ProblemDetail.forStatusAndDetail(HttpStatus.BAD_REQUEST, detail);
        pd.setType(URI.create("https://example.com/erros/validacao"));
        pd.setTitle("Requisição inválida");
        return ResponseEntity.status(HttpStatus.BAD_REQUEST)
                .contentType(MediaType.APPLICATION_PROBLEM_JSON).body(pd);
    }
}

using LojaApi.Domain.Events;
using LojaApi.Domain.Exceptions;
using LojaApi.Domain.ValueObjects;

namespace LojaApi.Domain.Entities;

/// <summary>
/// Aggregate Root de Produto — entidade rica (DDD).
/// Setters privados; invariantes garantidas no construtor/métodos.
/// </summary>
public class Produto
{
    private readonly List<IDomainEvent> _events = new();

    public int Id { get; private set; }
    public string Nome { get; private set; } = string.Empty;
    public Dinheiro Preco { get; private set; } = new(0);
    public int Estoque { get; private set; }
    public DateTime CriadoEm { get; private set; }

    /// <summary>Eventes de domínio pendentes (publicados após persistência).</summary>
    public IReadOnlyCollection<IDomainEvent> DomainEvents => _events.AsReadOnly();

    protected Produto() { }

    public Produto(int id, string nome, Dinheiro preco, int estoque)
    {
        Aplicar(nome, preco, estoque);
        Id = id;
    }

    /// <summary>Factory Method: criação controlada + publica evento.</summary>
    public static Produto Criar(string nome, Dinheiro preco, int estoque)
    {
        var p = new Produto(0, nome, preco, estoque);
        p._events.Add(new ProdutoCriadoEvent(p.Id, nome));
        return p;
    }

    /// <summary>Remove estoque com guarda de suficiência.</summary>
    /// <exception cref="DomainException">Se quantidade inválida ou estoque insuficiente.</exception>
    public void RemoverEstoque(int quantidade)
    {
        if (quantidade <= 0) throw new DomainException("Quantidade deve ser > 0");
        if (Estoque < quantidade) throw new DomainException("Estoque insuficiente");
        Estoque -= quantidade;
    }

    /// <summary>Eventes são limpos após dispatch.</summary>
    public void ClearEvents() => _events.Clear();

    private void Aplicar(string nome, Dinheiro preco, int estoque)
    {
        if (string.IsNullOrWhiteSpace(nome)) throw new DomainException("Nome é obrigatório");
        if (nome.Trim().Length < 2) throw new DomainException("Nome deve ter >= 2 caracteres");
        if (preco is null || preco.Valor <= 0) throw new DomainException("Preço deve ser > 0");
        if (estoque < 0) throw new DomainException("Estoque não pode ser negativo");
        Nome = nome.Trim(); Preco = preco; Estoque = estoque; CriadoEm = DateTime.UtcNow;
    }
}

using LojaApi.Application.DTOs;
using LojaApi.Domain.Entities;
using LojaApi.Domain.Exceptions;
using LojaApi.Domain.Interfaces;

namespace LojaApi.Application.Services;

/// <summary>Implementa os casos de uso. Recebe a INTERFACE IProdutoRepository (DIP).</summary>
public class ProdutoService : IProdutoService
{
    private readonly IProdutoRepository _repo;

    public ProdutoService(IProdutoRepository repo) { _repo = repo; }

    public async Task<ProdutoResponse> CriarAsync(CriarProdutoRequest req)
    {
        var produto = Produto.Criar(req.Nome, new Domain.ValueObjects.Dinheiro(req.Preco), req.Estoque);
        var salvo = await _repo.SalvarAsync(produto);
        return ProdutoMapper.ToResponse(salvo);
    }

    public async Task<List<ProdutoResponse>> ListarAsync()
    {
        var todos = await _repo.ListarAsync();
        return todos.Select(ProdutoMapper.ToResponse).ToList();
    }
    public async Task<List<ProdutoResponse>> ListarAsync(int page, int size)
    {
        var todos = await _repo.ListarAsync();
        return todos.Skip(page * size).Take(size).Select(ProdutoMapper.ToResponse).ToList();
    }

    public async Task<ProdutoResponse> ObterPorIdAsync(int id)
    {
        var p = await _repo.BuscarPorIdAsync(id)
            ?? throw new DomainException($"Produto não encontrado: {id}");
        return ProdutoMapper.ToResponse(p);
    }

    public async Task ExcluirAsync(int id)
    {
        if (!await _repo.ExistePorIdAsync(id))
            throw new DomainException($"Produto inexistente: {id}");
        await _repo.DeletarAsync(id);
    }
}

/// <summary>DbContext EF Core — mapeia Produto p/ tabela "produtos".</summary>

{

    public DbSet<Produto> Produtos => Set<Produto>();

    protected override void OnModelCreating(ModelBuilder mb)
    {
        mb.Entity<Produto>(e =>
        {
            e.ToTable("produtos");
            e.HasKey(p => p.Id);
            e.Property(p => p.Nome).HasMaxLength(100).IsRequired();
            e.Property(p => p.Estoque).IsRequired();
            e.Ignore(p => p.DomainEvents);          // eventos não persistem
            e.Ignore(p => p.Preco);                  // mapeado abaixo via OwnsOne
            e.OwnsOne(p => p.Preco, d =>
            {
                d.Property(x => x.Valor).HasColumnType("decimal(10,2)").HasColumnName("preco");
                d.Ignore(x => x.Moeda);
            });
        });
    }
}

using LojaApi.Domain.Entities;
using LojaApi.Domain.Interfaces;
using LojaApi.Domain.ValueObjects;
using MongoDB.Driver;

namespace LojaApi.Infrastructure.Mongo;

/// <summary>Adapter Mongo — mesma porta, tecnologia diferente (Liskov/Open-Closed).</summary>
public class MongoProdutoRepository : IProdutoRepository
{
    private readonly IMongoCollection<ProdutoMongoDocument> _col;

    public MongoProdutoRepository(IMongoClient client, string database)
    {
        _col = client.GetDatabase(database).GetCollection<ProdutoMongoDocument>("produtos");
    }

    public async Task<Produto> SalvarAsync(Produto p)
    {
        var doc = ToDoc(p);
        await _col.InsertOneAsync(doc);
        return p;
    }
    public async Task<Produto?> BuscarPorIdAsync(int id)
    {
        var doc = await _col.Find(d => d.IdLegado == id).FirstOrDefaultAsync();
        return doc is null ? null : ToDomain(doc);
    }
    public async Task<List<Produto>> ListarAsync()
    {
        var docs = await _col.Find(_ => true).ToListAsync();
        return docs.Select(ToDomain).ToList();
    }
    public async Task<bool> ExistePorIdAsync(int id) => await _col.CountDocumentsAsync(d => d.IdLegado == id) > 0;
    public async Task DeletarAsync(int id) => await _col.DeleteOneAsync(d => d.IdLegado == id);

    private ProdutoMongoDocument ToDoc(Produto p) => new()
    { IdLegado = p.Id, Nome = p.Nome, Preco = p.Preco.Valor, Estoque = p.Estoque };
    private Produto ToDomain(ProdutoMongoDocument d) => new(d.IdLegado, d.Nome, new Dinheiro(d.Preco), d.Estoque);
}

[ApiController]
[Route("api/auth")]
public class AuthController : ControllerBase
{
    private readonly IConfiguration _cfg;
    public AuthController(IConfiguration cfg) { _cfg = cfg; }

    public record LoginRequest(string Email, string Senha);

    [HttpPost("login")]
    public IActionResult Login([FromBody] LoginRequest req)
    {
        // TODO: validar contra base de usuários real
        if (req.Email != "dev@loja.com.br" || req.Senha != "SenhaForte#2026")
            return Unauthorized(new { type = "https://example.com/erros/auth", title = "Unauthorized", status = 401, detail = "Credenciais inválidas" });

        var key = new SymmetricSecurityKey(Encoding.UTF8.GetBytes(_cfg["Jwt:Secret"]!));
        var token = new JwtSecurityToken(
            claims: new[] { new Claim(ClaimTypes.Name, req.Email), new Claim(ClaimTypes.Role, "ADMIN") },
            expires: DateTime.UtcNow.AddMinutes(60),
            signingCredentials: new SigningCredentials(key, SecurityAlgorithms.HmacSha256));
        return Ok(new { tokenAcesso = new JwtSecurityTokenHandler().WriteToken(token), tipo = "Bearer", expiraEm = 3600 });
    }
}

using LojaApi.Domain.Exceptions;

namespace LojaApi.Api.Middleware;

/// <summary>Captura exceções e retorna RFC 7807 (application/problem+json).</summary>
public class ExceptionMiddleware
{
    private readonly RequestDelegate _next;
    public ExceptionMiddleware(RequestDelegate next) { _next = next; }

    public async Task Invoke(HttpContext ctx)
    {
        try { await _next(ctx); }
        catch (DomainException ex)
        {
            ctx.Response.StatusCode = 400;
            ctx.Response.ContentType = "application/problem+json";
            await ctx.Response.WriteAsync(JsonSerializer.Serialize(new
            {
                type = "https://example.com/erros/dominio",
                title = "Regra de negócio violada",
                status = 400,
                detail = ex.Message
            }));
        }
    }
}

🔄 Migração relacional → NoSQL (Strangler Fig — C#)




Motivações: escala horizontal, schema flexível. Riscos: perda de ACID, consistência eventual. A migração acontece DENTRO da API, via toggle Persistence:Provider no appsettings.json, trocando qual adapter é injetado no DI.




ADR-004 · Migração Strangler Fig com toggle 🔷 C#Aceita


Contexto: catálogo com atributos variáveis cresce; o relacional limita o schema; necessidade de escala horizontal sem downtime.


Decisão: migrar em 4 fases (dual-write → backfill → cut-over → desligamento) controladas por toggle (persistence.provider / Persistence:Provider), com a API escrevendo/lendo via porta ProdutoRepository/IProdutoRepository.


Alternativas consideradas: big-bang (rejeitada: downtime e risco); manter só relacional (rejeitada: limite de schema); CDC + ETL externo (rejeitada: complexidade de infra).


Consequências: (+) rollback trivial (1 chave), sem downtime, validação progressiva; (−) complexidade temporária de 2 adapters e necessidade de reconciliação.


Status: Aceita · Stakeholders: Backend, QA, SRE.


Ref: AWS ADR process.

namespace LojaApi.Infrastructure.Migration;

/// <summary>Backfill idempotente: copia dados históricos do MySQL → Mongo (fase 2).</summary>
public class BackfillJob
{
    private readonly EfProdutoRepository _ef;
    private readonly MongoProdutoRepository _mongo;

    public BackfillJob(EfProdutoRepository ef, MongoProdutoRepository mongo)
    { _ef = ef; _mongo = mongo; }

    public async Task RunAsync()
    {
        foreach (var p in await _ef.ListarAsync())
            await _mongo.SalvarAsync(p);   // upsert via IdLegado (idempotente)
    }
}

🔁 CI vs CD (o que é cada um)


    

  • CI (Integração Contínua): a cada push/PR o pipeline compila + testa automaticamente.
    • 

  • CD (Entrega Contínua): após CI verde, o artefato é empacotado e deixado pronto p/ deploy.
    • 

  • Pipeline / Stage / Job: pipeline = sequência; stage = fase (build, test); job = tarefa.
    • 

  • Runner: máquina/agente que executa os jobs.
    • 



Aprofundar: Martin Fowler (CI) · Atlassian CI/CD.




🖱️ Onde configurar (menus)


    

  1. GitLab: repo → Settings → CI/CD → habilitar Runners / Variables; o arquivo .gitlab-ci.yml na raiz ativa o pipeline automaticamente.
    2. 

  2. GitHub: repo → aba Actions → set up a workflow → criar .github/workflows/ci.yml.
    3. 

  3. Proteger a main: GitHub → Settings → Branches → Add rule → exigir checks; GitLab → Settings → Repository → Protected branches.
    4. 

  4. Testar: abrir um PR/MR de um branch feature/x → os checks rodam; ao mergear na main, rodam de novo.
    5.

ADR-002 · Clean Architecture em projetos .csproj 🔷 C#Aceita


Contexto: acoplamento domínio↔infra dificultava troca de banco.


Decisão: projetos Domain/Application/Infrastructure/Api/Tests com referências unidirecionais.


Alternativas consideradas: camadas por tecnologia (rejeitada); monolito (rejeitada).


Consequências: (+) testabilidade ↑; (−) custo inicial de scaffolding ↑.


Status: Aceita · Stakeholders: Backend C#, Arquitetura.


ADR-C1 · Domínio rico (DDD) com Value Objects e Domain Events 🔷 C#Aceita


Contexto: invariantes fortes e necessidade de publicar fatos de negócio.


Decisão: Aggregate Root Produto com setters privados; Dinheiro (VO, record); ProdutoCriadoEvent.


Alternativas consideradas: domínio anêmico (rejeitada p/ C#); CQRS (adiado).


Consequências: (+) invariantes garantidas, eventos p/ reações; (−) mais código de domínio.


Status: Aceita · Stakeholders: Backend C#.


ADR-C2 · EF Core como ORM padrão 🔷 C#Aceita


Contexto: persistência relacional com MySQL.


Decisão: EF Core (Pomelo MySQL); mapeamento via OnModelCreating (OwnsOne p/ VO).


Alternativas consideradas: Dapper (rejeitada: mais boilerplate); ADO.NET puro (rejeitada).


Consequências: (+) produtividade, migrações code-first; (−) abstração pode gerar queries ineficientes (monitorar).


Status: Aceita · Stakeholders: Backend C#, DBA.
