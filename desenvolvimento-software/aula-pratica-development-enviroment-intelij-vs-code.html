🌐 Fundamentos de Engenharia & Paridade Operacional

Antes de escrever código, garantimos paridade ambiental estrita: instalação declarativa e idempotente das ferramentas, eliminando o "na minha máquina funciona".

🛡️ O 10º Fator do Twelve-Factor App: Dev/Prod Parity

O 10º fator estabelece que o ambiente de desenvolvimento deve ser o mais parecido possível com o de produção. Divergências sutis (versão do JDK, libc, kernel) causam bugs silenciosos que só aparecem em produção.

🎯 Os 3 Pilares da Paridade

  1. Gerenciadores Declarativos: winget (Windows), apt (Linux), brew (macOS) — scripts auditáveis commitados no Git.
  2. Isolamento com WSL2: contêineres Docker sobre kernel Linux real (não emulado), com I/O e syscalls idênticos à produção.
  3. Trava de Versão via Git: .sdkmanrc (Java) e global.json (.NET) forçam a mesma versão de compiladores para todo o time.
🍳
Analogia da Cozinha Industrial: se cada chef usar balanças descalibradas e fogões diferentes, o prato nunca sai igual. Toda a rede usa a mesma fita métrica, os mesmos termômetros e a mesma bancada padronizada!

package com.example.hello.controller;

import org.springframework.web.bind.annotation.GetMapping;
import org.springframework.web.bind.annotation.RestController;

import java.time.Instant;
import java.util.Map;

/**
 * Controller REST de demonstração (smoke test do ambiente).
 *
 * <p>{@code @RestController} = {@code @Controller} + {@code @ResponseBody}:
 * todo retorno é serializado como JSON automaticamente.</p>
 *
 * @since 1.0.0
 */
@RestController
public class HelloController {

    /**
     * GET /hello — responde um JSON com mensagem, thread e horário.
     *
     * @return mapa serializado como JSON pelo Spring
     */
    @GetMapping("/hello")
    public Map<String, Object> hello() {
        return Map.of(
            "mensagem", "Hello World com Spring Boot 4 + Java 21!",
            "thread", Thread.currentThread().toString(),
            "horarioUtc", Instant.now().toString()
        );
    }

    /**
     * GET / — healthcheck simples com roteiro de testes.
     *
     * @return mapa JSON com status e próximo endpoint a testar
     */
    @GetMapping("/")
    public Map<String, String> raiz() {
        return Map.of(
            "status", "API Spring Boot no ar",
            "roteiro", "GET /hello"
        );
    }
}

📑 ADRs desta aba (registro global)

    
ADR-001 · Contrato OpenAPI como fonte únicaAceita

      
Contexto: frontend/mobile bloqueados aguardando backend.

      
Decisão: contrato OpenAPI 3.1 primeiro + mock Prism; negociado na Sala de Contrato.

      
Consequências: desenvolvimento paralelo; contrato = fonte da verdade.

    
ADR-005 · JWT statelessAceita

      
Contexto: autenticação sem sessão servidor.

      
Decisão: Bearer JWT HMAC-SHA256.

      
Consequências: escalabilidade horizontal; revogação exige blacklist/refresh.

    
ADR-007 · Mock Prism em validação estrita (-m false)Aceita

      
Contexto: mock dinâmico mascarava erros de contrato.

      
Decisão: Prism com -m false valida o body contra o schema e retorna 400 quando não bate.

      
Consequências: QA pega erros de contrato cedo; mock menos "mágico".

    
ADR-008 · Erros no padrão RFC 7807 (application/problem+json)Aceita

      
Contexto: erros ad-hoc dificultavam tratamento no cliente.

      
Decisão: todos os erros usam Problem Details (type/title/status/detail).

      
Consequências: clientes parseiam erros de forma uniforme.

package com.loja.application;
import com.loja.domain.Produto;
import com.loja.domain.ProdutoRepository;
import com.loja.domain.exception.DomainException;
import java.math.BigDecimal;
import java.util.List;

/** Casos de uso. Bean via CoreBeansConfig. @since 1.0.0 */
public class ProdutoServiceImpl implements com.loja.domain.ProdutoService {
    private final ProdutoRepository repository;
    public ProdutoServiceImpl(ProdutoRepository repository){ this.repository=repository; }

    @Override public Produto criarProduto(Produto p){
        if(p.getNome()==null||p.getNome().trim().isEmpty())
            throw new DomainException("O nome do produto é obrigatório");
        if(p.getNome().length()<2)
            throw new DomainException("O nome deve ter pelo menos 2 caracteres");
        if(p.getPreco()==null||p.getPreco().compareTo(BigDecimal.ZERO)<=0)
            throw new DomainException("O preço deve ser maior que zero");
        if(p.getEstoque()==null||p.getEstoque()<0)
            throw new DomainException("O estoque não pode ser negativo");
        return repository.salvar(p);
    }
    @Override public List<Produto> listarProdutos(){ return repository.listarTodos(); }
    @Override public Produto obterPorId(Long id){
        return repository.buscarPorId(id).orElseThrow(()->new DomainException("Não encontrado: "+id));
    }
    @Override public void excluirProduto(Long id){
        if(!repository.existePorId(id)) throw new DomainException("Inexistente: "+id);
        repository.deletarPorId(id);
    }
}

    @Override public Produto salvar(Produto p){ return toDomain(jpaRepo.save(toJpa(p))); }
    @Override public Optional<Produto> buscarPorId(Long id){ return jpaRepo.findById(id).map(this::toDomain); }
    @Override public List<Produto> listarTodos(){ return jpaRepo.findAll().stream().map(this::toDomain).toList(); }
    @Override public boolean existePorId(Long id){ return jpaRepo.existsById(id); }
    @Override public void deletarPorId(Long id){ jpaRepo.deleteById(id); }

    private ProdutoJpaEntity toJpa(Produto d){
        ProdutoJpaEntity e=new ProdutoJpaEntity();
        e.setId(d.getId()); e.setNome(d.getNome()); e.setPreco(d.getPreco()); e.setEstoque(d.getEstoque());
        return e;
    }
    private Produto toDomain(ProdutoJpaEntity e){
        return new Produto(e.getId(), e.getNome(), e.getPreco(), e.getEstoque());
    }
}

package com.loja.presentation.security;
import io.jsonwebtoken.*;
import io.jsonwebtoken.security.Keys;
import org.springframework.beans.factory.annotation.Value;
import org.springframework.stereotype.Service;
import java.security.Key;
import java.util.Date;

/** Geração/validação de JWT (HMAC-SHA256). @since 1.0.0 */
@Service
public class JwtService {
    @Value("${jwt.secret}") private String secret;
    @Value("${jwt.expiration}") private long expiration;
    private Key key(){ return Keys.hmacShaKeyFor(secret.getBytes()); }

    public String gerarToken(String username, String role){
        return Jwts.builder().setSubject(username).claim("role", role)
            .setIssuedAt(new Date()).setExpiration(new Date(System.currentTimeMillis()+expiration))
            .signWith(key(), SignatureAlgorithm.HS256).compact();
    }
    public String extrairUsername(String t){ return claims(t).getSubject(); }
    public String extrairRole(String t){ return claims(t).get("role", String.class); }
    public boolean isTokenValido(String t){
        try { claims(t); return true; } catch (JwtException | IllegalArgumentException e){ return false; }
    }
    private Claims claims(String t){
        return Jwts.parserBuilder().setSigningKey(key()).build().parseClaimsJws(t).getBody();
    }
}

package com.loja.presentation.security;
import jakarta.servlet.FilterChain;
import jakarta.servlet.ServletException;
import jakarta.servlet.http.HttpServletRequest;
import jakarta.servlet.http.HttpServletResponse;
import org.springframework.security.authentication.UsernamePasswordAuthenticationToken;
import org.springframework.security.core.authority.SimpleGrantedAuthority;
import org.springframework.security.core.context.SecurityContextHolder;
import org.springframework.stereotype.Component;
import org.springframework.web.filter.OncePerRequestFilter;
import java.io.IOException;
import java.util.List;

/** Filtro que valida Bearer JWT e popula o SecurityContext. @since 1.0.0 */
@Component
public class JwtTokenFilter extends OncePerRequestFilter {
    private final JwtService jwt;
    public JwtTokenFilter(JwtService jwt){ this.jwt=jwt; }

    @Override protected void doFilterInternal(HttpServletRequest req, HttpServletResponse res, FilterChain chain)
            throws ServletException, IOException {
        String h = req.getHeader("Authorization");
        if (h != null && h.startsWith("Bearer ")) {
            String token = h.substring(7);
            if (jwt.isTokenValido(token)) {
                var auth = new UsernamePasswordAuthenticationToken(jwt.extrairUsername(token), null,
                    List.of(new SimpleGrantedAuthority("ROLE_" + jwt.extrairRole(token))));
                SecurityContextHolder.getContext().setAuthentication(auth);
            } else {
                res.setStatus(401);
                res.setContentType("application/problem+json");
                res.getWriter().write("{\"erro\":\"Token inválido\"}");
                return;
            }
        }
        chain.doFilter(req, res);
    }
}

namespace LojaApi.Domain.Entities;

/// <summary>Aggregate Root de Produto — entidade rica (DDD).</summary>
public class Produto
{
    public int Id { get; private set; }
    public string Nome { get; private set; } = string.Empty;
    public decimal Preco { get; private set; }
    public int Estoque { get; private set; }
    public DateTime CriadoEm { get; private set; }

    protected Produto() { }

    public Produto(int id, string nome, decimal preco, int estoque)
    {
        if (preco <= 0) throw new Exceptions.DomainException("Preço deve ser > 0");
        Id = id; Nome = nome; Preco = preco; Estoque = estoque; CriadoEm = DateTime.UtcNow;
    }

    public static Produto Criar(string nome, decimal preco, int estoque) => new(0, nome, preco, estoque);

    public void RemoverEstoque(int q)
    {
        if (q <= 0) throw new Exceptions.DomainException("Quantidade deve ser > 0");
        if (Estoque < q) throw new Exceptions.DomainException("Estoque insuficiente");
        Estoque -= q;
    }
}
